## 0–5 分钟：说清实验对象

固定 10 MiB 顺序图、预热文件页缓存，比较两个实现和两个负载。

| 组 | 实现 | 负载 |
|---|---|---|
| A | read/lseek | 读 |
| B | read/lseek | 读并更新 value |
| C | mmap | 读 |
| D | mmap | 读并更新 value |

每组 **30 次独立进程运行**，每进程 **20 遍**；主系列共 120 条记录，统计样本数每组为 30。准备时的复制、sync 和预热不在主计时范围内，进程启动和遍历等开销包含在内。

## 5–10 分钟：解释实现与缓存

| 概念 / Термин | 30 秒中文解释 |
|---|---|
| read / lseek | lseek 调整文件偏移，read 把数据送到程序缓冲区；页缓存命中仍可能有系统调用和复制成本。 |
| mmap / отображение файла | 将文件映射到虚拟地址空间，经地址访问数据；不是先复制整文件，也不表示绕过操作系统。 |
| 文件页缓存 / файловый кеш | 内核管理文件数据页。实验预热的是这一层，不能据此声称 CPU 缓存全部命中。 |
| CPU 缓存 / кеш CPU | 处理器的 L1/L2/L3 缓存行；与文件页缓存、虚拟地址空间分别解释。 |
| minor / major fault | minor 通常无需后备存储读取，major 需要 I/O；某个计数为零不能代表系统完全没有 I/O。 |
| MAP_SHARED / грязная страница | 映射写入可修改共享文件页，形成脏页；没有逐次等待持久化，不能把耗时直接解释为磁盘写速。 |

## 10–15 分钟：解释统计与结论

$$
\bar x=\frac{1}{n}\sum x_i,\qquad
s=\sqrt{\frac{\sum(x_i-\bar x)^2}{n-1}},\qquad
CI=\bar x\pm t_{0.975,n-1}\frac{s}{\sqrt n}.
$$

标准差描述运行离散程度，标准误描述均值估计的随机波动；置信区间不覆盖所有系统误差。只有每组主系列的独立运行数量进入 n，不能用每进程的遍历次数放大样本数。

原资料记录的平均毫秒 / 遍：A 97.7952、B 240.5746、C 1.5607、D 3.3886。这些数仅适用于当前数据、实现、参数和计时协议。比较结果时同时说明：

- perf 未得到当前 WSL 内核对应的计数器，不能填成 0。
- 两种时钟在 37/120 次运行中差异超过 1 ms，最大 8.593230 秒，原因未确定。
- N=30 为设定值，5% 半宽是事后检查。
- 工具对照每配置 / 工具仅一次，不能计算单点标准差或置信区间。

## 俄语 30 秒

> Я сравниваю read/lseek и mmap при чтении и изменении последовательного графа размером 10 МиБ с прогретым файловым кешем. Для каждой из четырёх конфигураций выполнено 30 запусков, по 20 обходов в процессе. Я показываю среднее время и доверительный интервал, но отдельно указываю расхождение часов и отсутствие счётчиков perf. Вывод относится только к этому протоколу измерений.
