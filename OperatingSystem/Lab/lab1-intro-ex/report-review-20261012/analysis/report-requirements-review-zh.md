## 需要保持准确的判断

1. N=30 是否足够回答本次 Read/Write 比较，报告已经回答；“当前足够”与“已事前按 pilot 算出 N”是不同事实。
2. 日历时钟不一致本身不证明单调时钟错误，报告对绝对精度的限制是谨慎表述，不能把所有单调数据自动作废，也不能用窄 CI 掩盖系统性误差。
3. 混合负载的新 C 不是原 CPU-only 对照的更正确替代；CPU-only 已能展示课程要求的噪声测量。
4. 报告中的 mmap CPU 对照已有三对数据。本次历史目录只有一个 LOAD_API 的 C，不能额外宣称完成了两种 API 的新混合负载。
5. 事前记录不能在事后补写并冒充原始计划。现有报告可如实保留方法限制；后续重复实验才可采用事前写好的计划。
