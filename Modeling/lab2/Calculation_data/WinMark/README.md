# WinMark 实际计算文件

程序：`../../WinMark/WinMark.exe`，版本 1.0.0.1。

- `system1.mrk`、`system2.mrk`：已在 WinMark 中实际计算并保存的完整工程，含矩阵、概率、公式和指标。
- 同名 `.html`：WinMark 原生导出的结果。
- `system1_formulas.tsv`、`system2_formulas.tsv`：输入公式，便于检查；其中 `p0` 对应 `S0`。
- `Variation/`：λ 从 0.1 到 1.0 的二十次实际计算工程和 HTML 输出。
- `verification.json`：与独立高精度解逐项比较的记录。

打开 WinMark，在“Файл → Загрузить”选取工程；“Расчёт → Вероятности”计算稳态概率，“Расчёт → Формулы”计算指标。报告数值来自实际输出，Python 用于独立核对。

矩阵的文本编辑窗口确认保存时会舍入到四位小数。最终工程已经保留完整精度，可以直接读取和计算；重新编辑矩阵时应注意这一程序特性。输出的六位小数不表示六位准确度。

参数变化采用逐点重复计算，没有使用内置“Варьирование”菜单。原封面与参考资料保留；临时渲染及测试输出已移至回收站。
