# 字体、代码精简与三语切换

更新日期：2026-10-03。

## 字体与字号

- 俄语和英文正文优先使用已有 Bahnschrift，中文使用 Microsoft YaHei，其余客户端自动使用系统备用字体。
- 登录页 CITY 使用本机已安装的 BLASTIMO SANS，并调整字体尺寸和基线，避免字形超出拼图；未安装时使用 Impact 等备用字体。
- 正文和输入框为 16px，表头、表单标签、说明及错误信息以 14px 为主，表格内容为 15px。
- 字体通过 CSS 的 `local()` 或字体名称引用，不复制字体文件、不请求外部字体服务。学校服务器不需要安装这些字体；字体由访问网页的浏览器选择。

## 精简内容

清理了被删除的装饰文案对应的样式，合并页尾覆盖规则，将字体、基础样式与语言控件样式放入 ui.css。
分页中重复读取页面大小的代码合并为一次；表单验证的多层条件改为简单的提示词典。
CSS 总体比修改前减少约 15%；新增多语言词典会增加必要代码，因此整个前端不承诺零增长。

业务层检查后保留现有分层、事务、字段校验、排序白名单、版本冲突校验、64 位整数处理及两秒轮询。这些代码对应实验行为，删掉它们会损失功能。
没有引入前端框架、第三方国际化库或新的构建工具，也没有修改已执行过的数据库迁移。

## 语言切换

参考本机 Programming Lab8 中的 `LocalizationManager.getString(key)` 与 `updateUITexts()`：

1. i18n.js 中的词典集中存放中文、英文译文，原文作为键。
2. `I18n.t(key)` 类似 Lab8 的 `getString(key)`，按当前语言取文案。
3. HTML 使用 `data-i18n` 明确标记需要翻译的文字；占位符和无障碍标签有各自的标记。
4. 动态提示通过 `I18n.text(element, key)` 更新，动态 HTML 中的固定文案使用 `I18n.html(key)`。
5. 下拉框切换语言后更新这些标记；localStorage 记住偏好。没有自动翻译数据库内容，也没有重建编辑表单。

登录页与主页均可切换语言。账号、城市名称、关联对象名称、输入值、API 字段名、枚举值和数据库内容不因切换语言而改变。

新增一个界面文案时，把译文加入 words 词典，然后给对应元素加 `data-i18n`，或使用上述动态更新方法即可。

## 下个实验与 Thymeleaf

Thymeleaf 可以与 Spring MVC、EclipseLink 和 PostgreSQL 一起使用，它负责服务端 HTML 模板渲染，不替换持久化层。
但把现有静态 HTML 移动到 templates 不会自动替代 JavaScript：弹窗、异步查询、两秒刷新仍需要浏览器代码。

若实验二只是增加几个功能，优先沿用当前 HTML + JavaScript，在现有菜单、接口和服务中扩展。
若新增多个服务端页面且出现明显重复布局，再针对这些新页面使用 Thymeleaf 的模板片段与 Model；不必重写已有业务界面。
是否允许使用，需要核对实验二的实际要求。官方说明：[Thymeleaf 与 Spring MVC 集成](https://www.thymeleaf.org/doc/tutorials/3.1/thymeleafspring.html)。
