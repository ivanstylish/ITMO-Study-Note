# Выводы по работе

В ходе лабораторной работы разработана информационная система для управления объектами City варианта 5742 на основе Spring MVC, EclipseLink и PostgreSQL. Реализованы CRUD-операции, проверка данных, работа со связанными объектами, пагинация, фильтрация и сортировка. Специальные операции вынесены в функции базы данных. Автоматическое обновление интерфейса и оптимистическая блокировка обеспечивают согласованную работу нескольких пользователей. Закреплены навыки применения ORM, транзакций и разделения приложения на слои.
