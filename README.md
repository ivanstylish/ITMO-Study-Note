## 三条复习路线

- **数值计算与机器学习**：线性代数 → 计算数学 → 统计与建模 → 人工智能。
- **计算机系统与测量**：OPD → 体系结构 → 操作系统 → 性能与统计测量。
- **请求、数据与软件设计**：数据库 → Web → 软件工程 → 信息系统。

在[知识地图](knowledge/index.md)中找到各条路线的原笔记、实例和自测问题。
