### 3.1 数据是什么

数据是实验一的 `Student_Performance.csv`，目标变量是连续的 `Performance Index`。因此这是回归问题，应使用 MSE 和 R²，不使用分类实验中的 log loss 和 accuracy。

`frames[0]` 是训练集。填充参数先在这一行确定，然后供三份数据使用。验证和测试数据不参与估计填充值。

```python

category = frame[CATEGORY].fillna(mode)
```

标准化参数在 `main` 中也只从训练集计算。

[定位训练集标准化](D:/Study-Note/AISystem/Labs/lab3/regularization.py:106)

```python
mean = frames[0][features].mean().to_numpy()
scale = frames[0][features].std(ddof=0).to_numpy(copy=True)
scale[scale == 0] = 1
x = [design_matrix(frame, features, mean, scale) for frame in frames]
```

标准化公式是

\[
z_j=\frac{x_j-\mu_j}{s_j}
\]

`ddof=0` 表示除以训练样本数量的标准差定义。零标准差改为 1，可以避免除以零。`copy=True` 使得到的数组可以安全修改。

验证和测试必须使用训练集的均值与标准差。如果分别用各自统计量标准化，同一个输入值会被变成不同坐标，模型接收的输入含义就不一致。

使用全部数据计算这些参数，也会让训练提前接触留出数据的分布信息。这就是数据泄漏。

标准化还使正则化更公平。原始“历史成绩”的数值范围远大于“课外活动”的 0 和 1，直接惩罚原始系数会受到计量单位影响。

## 5 报告第 4 页 预测和指标

### 5.1 设计矩阵为什么加一列 1

[定位 design_matrix](D:/Study-Note/AISystem/Labs/lab3/regularization.py:54)

```python
z = (frame[features].to_numpy(dtype=float) - mean) / scale
return np.column_stack([np.ones(len(z)), z])
```

如果有 p 个特征，设计矩阵 `X` 的形状是 `n × (p+1)`，权重向量 `w` 的长度是 `p+1`。第一列全是 1，对应截距 `w[0]`。

\[
\widehat y_i=b+\sum_{j=1}^{p}w_jz_{ij}
\]

代码中的 `X @ w` 一次计算所有样本的预测。此处 `@` 是矩阵乘法。`w[0]` 是 b，`w[1:]` 是特征系数。

### 5.2 MSE 和 R² 如何计算

[定位 evaluate](D:/Study-Note/AISystem/Labs/lab3/regularization.py:59)

\[
\operatorname{MSE}=\frac{1}{n}\sum_i(y_i-\widehat y_i)^2
\]

\[
R^2=1-\frac{\sum_i(y_i-\widehat y_i)^2}{\sum_i(y_i-\overline y)^2}
=1-\frac{\operatorname{MSE}}{\operatorname{Var}(y)}
\]

```python
error = y - prediction
mse, variance = float(np.mean(error ** 2)), float(np.var(y))
```

MSE 越小越好，单位是目标单位的平方。RMSE 是 MSE 的平方根，回到原始目标单位。MAE 是绝对误差的平均值。

R² 越接近 1 越好。R² 为 0，表示预测误差等于使用这份评价数据的目标均值作为常数预测的误差。R² 可以为负，表示比这个均值基线更差，不能称为“准确率”。

每份数据都用它自身的目标均值计算 R²。训练、验证、测试的 R² 分母不同，所以不能把两个集合的 MSE 大小直接当作 R² 大小的完全等价比较。

**RU 可以直接说**

Прогноз вычисляется как X умножить на w. Первый столбец X состоит из единиц и задаёт свободный член. MSE измеряет средний квадрат ошибки. R² сравнивает модель с прогнозом среднего значения и может быть отрицательным.

## 6 报告第 4 页 三种罚项如何统一实现

本版使用同一个目标函数

\[
J=\operatorname{MSE}
+\lambda\left[\rho\sum_{j=1}^{p}|w_j|
+\frac{1-\rho}{2}\sum_{j=1}^{p}w_j^2\right]
\]

| 方案 | λ | ρ | 产生的目标函数 |
|---|---|---|---|
| 无正则化 | 0 | 0 | 只有 MSE |
| L1 | 大于 0 | 1 | MSE 加 λ 倍绝对值之和 |
| L2 | 大于 0 | 0 | MSE 加 λ/2 倍平方和 |
| ElasticNet | 大于 0 | 0 到 1 之间 | 同时加入两种罚项 |

λ 控制整体罚项强度，ρ 控制 L1 的比例。ρ 越接近 1，L1 的比例越大。

注意，我们的 L2 有 1/2 因子，所以 L2 部分的梯度是 `λ(1-ρ)w`，不是再多乘一个 2。其他公式定义下的 λ 数值不能直接照搬。

所有罚项求和都从第一个特征系数开始，没有截距 b。代码通过 `w[1:]` 保证这一点。

**RU 可以直接说**

Все варианты реализованы одной функцией. При λ равном нулю штраф отсутствует. При ρ равном единице получаем L1, при ρ равном нулю получаем L2. Промежуточное значение ρ задаёт ElasticNet. Свободный член не регуляризуется.

## 7 报告第 4 页 核心训练函数逐步讲解

[定位 fit](D:/Study-Note/AISystem/Labs/lab3/regularization.py:66)

先抓住核心更新的四行。

```python
gradient = 2 * (gram @ w - cross)
gradient[1:] += strength * (1 - ratio) * w[1:]
w -= rate * gradient
w[1:] = np.sign(w[1:]) * np.maximum(np.abs(w[1:]) - rate * strength * ratio, 0)
```

函数参数 `strength` 对应 λ，`ratio` 对应 ρ，`rate` 对应学习率 η。

### 7.1 为什么先算 gram 和 cross

MSE 的完整梯度是

\[
\nabla J_{\mathrm{MSE}}=\frac{2}{n}X^T(Xw-y)
\]

展开后得到

\[
\nabla J_{\mathrm{MSE}}
=2\left(\frac{X^TX}{n}w-\frac{X^Ty}{n}\right)
\]

因此提前计算

```python
gram, cross = x.T @ x / len(y), x.T @ y / len(y)
```

后续每次迭代只计算 `2 * (gram @ w - cross)`。这与直接按所有训练样本计算完整梯度等价，不是抽样训练，也没有改变目标函数。

`gram` 的形状是 `(p+1) × (p+1)`，`cross` 是长度为 `p+1` 的向量。它们只使用训练集。

### 7.2 L2 梯度在哪里

```python
gradient[1:] += strength * (1 - ratio) * w[1:]
```

它只改变特征部分的梯度。截距对应的 `gradient[0]` 保留纯 MSE 梯度。

### 7.3 为什么 L1 使用软阈值

绝对值在零点不可导。我们先对平滑部分，也就是 MSE 和 L2，做梯度下降，再对 L1 使用近端更新。

\[
v_j=w_j-\eta\left[\nabla_j\operatorname{MSE}+\lambda(1-\rho)w_j\right]
\]

\[
w_j=\operatorname{sign}(v_j)
\max\left(|v_j|-\eta\lambda\rho,0\right)
\]

这叫近端梯度下降，是一阶梯度方法。它不需要借助任何现成优化器。

例如阈值是 0.1，更新后的临时系数为 0.06，则结果是 0。临时系数为 0.30，则结果是 0.20。临时系数为 -0.30，则结果是 -0.20。

不能用“每步减去 λ 倍符号”来说明当前实现，因为当前代码实际使用的是软阈值，它可以直接得到严格零。

### 7.4 为什么历史有 10001 个点

```python
for step in range(steps + 1):
```

先记录当前状态，达到最后一个编号后退出，不再做一次更新。编号 0 是零初始权重，编号 10000 是经过 10000 次更新后的权重。

所有方案都使用零初始权重、学习率 0.05、10000 次更新，没有提前停止。验证误差只被记录，不决定停止时间。

### 7.5 记录曲线时是否包含罚项

```python
train, val = evaluate(y, x @ w), evaluate(yv, xv @ w)
history.append([train["MSE"], val["MSE"], train["R2"], val["R2"]])
```

这里直接调用 `evaluate`，只算预测误差，不加罚项。训练更新使用带罚项的目标，评价曲线使用不带罚项的 MSE，两者用途不同。

**RU 可以直接说**

Используется проксимальный градиентный спуск. Сначала выполняется шаг по MSE и L2, затем применяется мягкий порог для L1. Обе операции регуляризации затрагивают только w начиная с индекса 1. История содержит начальную точку и 10000 обновлений. На графиках показана MSE без штрафа.

| 条件 | 所有候选和最终方案共同使用的值 |
|---|---|
| 数据划分 | 相同的训练、验证、测试行号 |

| 初始权重 | 全零 |
| 学习率 | 0.05 |

| 绘图评价误差 | 不包含正则化罚项的 MSE |

选参代码是

[定位验证集选参](D:/Study-Note/AISystem/Labs/lab3/regularization.py:125)

```python
best = min(candidates, key=lambda row: (row["validation_MSE"], row["lambda"], row["l1_ratio"]))
```

首先比较验证 MSE。如果恰好相同，优先较小的 λ，再优先较小的 ρ。测试指标没有进入这个表达式。

## 9 报告第 6 页 参数影响怎么解释

三个图分别对应三组特征，每个图包含 L1、L2 和 ElasticNet 三个面板。横轴是 λ，纵轴是验证 MSE。ElasticNet 的三条线对应三个 ρ。

较大的 λ 会增强系数惩罚，但不会保证验证误差更小。过强惩罚会提高模型偏差，导致欠拟合。

模型 3 的例子最明显。

| 设置 | 验证 MSE |
|---|---:|
| 无正则化 | 4.304388 |
| L1，λ=10 | 42.809962 |
| L2，λ=10 | 222.392209 |
| ElasticNet，λ=10，ρ=0.2 | 210.158487 |
| ElasticNet，λ=10，ρ=0.8 | 122.675560 |

较大的 ρ 在这个强罚项例子中降低了误差，但它仍明显差于弱正则化和无正则化。不能因此说“ρ 越大越好”。结论只针对本次网格和数据。

代码通过 `for strength, ratio in parameters` 枚举所有组合，将训练与验证指标写入 `hyperparameter_results.csv`。`graphics.py` 读取这些结果绘图，不重新训练，也不通过测试集反向选参。

**RU 可以直接说**

## 10 报告第 7 到 9 页 四类曲线怎么读

## 12 报告第 11 页 系数和稀疏性

[定位 weight_statistics](D:/Study-Note/AISystem/Labs/lab3/regularization.py:89)

```python
slopes = w[1:]
```

统计从这一行开始排除截距。L1 范数是特征系数绝对值之和，L2 范数是特征系数平方和的平方根。它们帮助比较整体权重规模。

严格零是 `w == 0`。接近零是 `abs(w) <= 0.1`，这是本实验明确声明的标准化系数阈值，并非通用统计检验标准。

最终选定参数下没有严格零。模型 3 的交互特征在以下方案中接近零。

| 方案 | 交互特征标准化系数 |
|---|---:|
| 无正则化 | 0.044847 |
| L1 | 0.048011 |
| L2 | 0.185687 |
| ElasticNet | 0.076001 |

L2 的交互特征系数反而增加，但整体 L2 范数从约 19.033925 降到 18.922670。交互特征与原有特征相关，惩罚会重新分配它们之间的权重。整体范数变小，不要求每个系数都变小。

在 λ=10 的额外网格实验中，L1 在模型 1、2、3 中分别产生 2、1、4 个严格零。完整模型中被置零的是学习时间、睡眠时间、练习数量和课外活动，交互特征仍保留。

这不表示学习时间没有预测价值。交互特征本身包含学习时间，强惩罚下相关特征可以互相替代。此时验证 MSE 已显著增加，所以不能为追求稀疏就选这组参数。

### 原始单位系数如何恢复

[定位 original](D:/Study-Note/AISystem/Labs/lab3/regularization.py:132)

\[
\beta_j=\frac{w_j}{s_j}
\qquad
b_{\mathrm{original}}=b-\sum_j\frac{w_j\mu_j}{s_j}
\]

```python
original = np.r_[w[0] - np.sum(w[1:] * mean / scale), w[1:] / scale]
```

标准化后的权重便于在同一模型内比较尺度，原始单位系数便于写出实际预测公式。两种表示给出同样预测，系数本身不能证明因果关系。

**RU 可以直接说**

При выбранных параметрах строгих нулей нет. Взаимодействие близко к нулю в трёх вариантах при пороге 0,1. При λ равном 10 L1 создаёт нули, но заметно ухудшает ошибку. L2 уменьшает общую норму, хотя отдельный коэффициент коррелирующего признака может увеличиться.

## 13 报告第 12 页 结论怎么组织

结论应连接实验现象和对应证据。

1. 三组特征的差异远大于弱正则化方案的差异。证据是测试 R² 从约 0.1465 到 0.9886 的变化。

Главное влияние оказывает состав признаков. Регуляризация ограничивает коэффициенты, но на этом наборе её влияние на качество невелико. Слишком большой штраф приводит к недообучению. Параметры следует выбирать по валидационной ошибке, а не по числу нулевых весов.

## 17 常见追问与俄语回答

### 为什么不正则化截距

截距调整整体目标水平，不表示某个特征的复杂度。如果惩罚它，会把整体预测水平也压向 0。

**RU** Свободный член задаёт общий уровень прогноза. Его штрафование смещало бы прогноз к нулю, поэтому в работе штрафуются только коэффициенты признаков.

### 为什么标准化二元特征

本实验统一标准化所有输入，使罚项比较在同一个尺度下进行。映射为 0 和 1 不表示它必须保持这个数值尺度进入正则化模型。

**RU** Бинарный признак тоже стандартизируется, чтобы коэффициенты всех признаков штрафовались в сопоставимом масштабе.

### 为什么误差图不能加正则化罚项

不同方案和 λ 的罚项不同。使用纯 MSE 才能直接比较预测误差。

**RU** Разные штрафы имеют разные масштабы. Для сравнения качества прогноза на графиках используется только MSE без штрафа.

### 没有零系数是不是 L1 没实现好

不是。最优验证参数的 λ 很弱，不足以将这些系数置零。λ=10 的实验和精确解测试都验证了零系数。

**RU** Нет. При выбранной слабой λ веса могут оставаться ненулевыми. При λ равном 10 и в независимом тесте мягкий порог действительно создаёт строгие нули.

### L2 为什么让交互系数变大

罚项约束的是整体平方和，相关特征的贡献可以重新分配。整体范数下降，不意味着每个权重下降。

**RU** При коррелирующих признаках вклад перераспределяется. L2 уменьшает общую норму, но отдельный коэффициент может вырасти.

### 为什么模型 1 不能靠正则化变得很好

它缺少历史成绩这个关键输入。正则化限制权重，不会创造缺失的信息。

**RU** В первой модели нет Previous Scores. Регуляризация ограничивает веса, но не добавляет недостающую информацию.

### 验证误差小于训练误差是否有问题

随机划分得到的两组数据难度可以不同。负差距本身不是泄漏证据，需检查处理流程和样本是否独立。

**RU** Это возможно из-за случайных различий между выборками. Сам по себе отрицательный разрыв не означает утечку данных.

### 为什么不合并训练和验证重新训练

任务需要保留验证曲线。当前实现使曲线和测试评价对应同一套权重，也保持统一比较条件。

**RU** Я сохраняю валидационную выборку независимой. Поэтому кривые и тестовые метрики относятся к одной и той же обученной модели.

### 近端梯度是不是符合梯度下降要求

它是处理不可导罚项的一阶梯度方法。平滑部分使用梯度下降，L1 部分使用精确近端操作，并非调用外部优化器。

**RU** Да. Это вариант градиентного метода для негладкого штрафа. Гладкая часть обновляется по градиенту, а L1 обрабатывается собственной операцией мягкого порога.

### 正则化是不是一定避免过拟合

它可以降低方差，但也增加偏差。λ 太大会欠拟合。结果取决于数据、模型和参数。

**RU** Регуляризация может уменьшать дисперсию, но увеличивает смещение. Слишком большой штраф приводит к недообучению.

### 哪组方案最好

先说明比较准则。按验证 MSE，完整特征模型的无正则化方案最好。其测试 R² 约为 0.9886。不要说是“看测试挑出的最佳方案”。

**RU** По валидационной MSE лучшим оказался полный набор признаков без штрафа. Его тестовое R² равно примерно 0,9886.

### 78 次是不是总训练调用次数

78 是不同候选配置的数量。另有 12 次按已选参数重新训练，用于记录曲线，所以实际 `fit` 调用共 90 次。

**RU** 78 — это число разных конфигураций. Ещё 12 обучений повторяются с выбранными параметрами для записи истории. Всего функция fit вызывается 90 раз.
