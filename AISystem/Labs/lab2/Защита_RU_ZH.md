## 3. Данные и защита от утечки — 为什么这样处理数据

**RU:** Нули в глюкозе, давлении, толщине кожной складки, инсулине и ИМТ обозначают некорректные измерения и рассматриваются как пропуски. Ноль беременностей допустим. Нельзя заменять все нули во всей таблице.

**中文：** 血糖、血压、皮褶厚度、胰岛素、BMI中的零值按隐式缺失处理，但怀孕次数为0有实际意义。不能把全表的0都替换，尤其不能修改标签0。

```python
X[MISSING] = X[MISSING].replace(0, np.nan)
```

缺失数分别是5、35、227、374、11。原始表虽没有空白单元格，却不代表没有缺失信息。

**RU:** Медиана менее чувствительна к большим выбросам, чем среднее. Она вычисляется на обучении. На проверке и тесте используются уже сохранённые медианы.

**中文：** 相比均值，中位数受极端值影响较小。训练时计算一次，验证和测试使用已有参数；如果分别计算，训练流程就利用了不该知道的分布信息。

```python
if parameters is None:
    medians = X.median()
    filled = X.fillna(medians)
    parameters = medians, filled.mean(), filled.std(ddof=0).replace(0, 1)
medians, means, scales = parameters
X = ((X.fillna(medians) - means) / scales).to_numpy()
```

**RU:** Стандартизация приводит признаки к сопоставимым масштабам и облегчает оптимизацию. Нулевая дисперсия заменяется масштабом 1, чтобы избежать деления на ноль.

**中文：** 特征单位不同，标准化可改善优化时的数值尺度。常量列标准差为0，改为1避免除零。

$$x'_{ij} = \frac{x_{ij}-\mu_j}{s_j}.$$

这里标准化使用 `ddof=0`，即分母为样本数n；描述统计 `describe()` 的标准差使用 `ddof=1`。两者用于不同目的，并不矛盾。

**RU:** Разбиение сначала 80/20: 614 объектов для разработки и 154 для теста. Затем четверть первой части выделяется для проверки. Получается 460/154/154. Стратификация сохраняет доли классов с небольшим округлением, а начальное значение 42 делает запуск воспроизводимым.

**中文：** 先按80/20分开发集和测试集，再从开发集中取约四分之一作为验证集，得到460/154/154。分层保证类别比例近似一致；42是随机种子，不是模型参数。

## 4. Формулы и их выражение в коде — 公式如何落到代码

### 4.1. Линейный предиктор и свободный член — 线性预测与截距

$$z_i=b+x_i^Tw,\quad z=X\theta.$$

```python
np.column_stack([np.ones(len(X)), X])
z = X @ weights
```

**RU:** После добавления столбца единиц первый вес становится свободным членом. Для 460 объектов и восьми признаков матрица X имеет размер 460×9, вектор весов — 9, векторы z, p и y — 460. Символ `@` обозначает матричное умножение.

**中文：** 添加全1列后，权重第一个元素就是截距。训练矩阵460×9，权重长度9，输出长度460。截距列是在标准化之后添加的，因此不会被减成0。

### 4.2. Сигмоида — 概率输出

$$\sigma(z)=\frac{1}{1+e^{-z}}.$$

```python
e = np.exp(-np.abs(z))
return np.where(z >= 0, 1 / (1 + e), e / (1 + e))
```

**RU:** При z≥0 применяется обычная форма. При z<0 используется равносильная форма exp(z)/(1+exp(z)). Экспонента не получает большого положительного аргумента, поэтому нет переполнения при z=−1000.

**中文：** 当z非负时用普通形式；z负时用等价的exp(z)/(1+exp(z))。指数输入始终非正，不会计算exp(1000)。注意 `np.where` 会先计算两个分支，因此不能直接在两个分支中放可能溢出的指数；这里先计算安全的e。

### 4.3. Правдоподобие и функция потерь — 最大似然与交叉熵

$$P(y_i\mid x_i)=p_i^{y_i}(1-p_i)^{1-y_i},$$
$$L=-\frac1n\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].$$

利用 $\log p=z-\log(1+e^z)$，可得：

$$L=\frac1n\sum_i[\log(1+e^{z_i})-y_i z_i].$$

```python
return float(np.mean(np.logaddexp(0, z) - y * z))
```

**RU:** `logaddexp(0,z)` устойчиво вычисляет log(1+exp(z)). Функция принимает логиты z, а не вероятности p. Это исключает прямое вычисление log(0) и сохраняет штраф за уверенный неправильный ответ.

**中文：** `log_loss`接收的是线性输出z，不是sigmoid后的p。`logaddexp`稳定计算log(1+exp(z))，避免log(0)，不需要先把概率截断。

### 4.4. Градиент — 为什么是 p−y

$$\frac{\partial L_i}{\partial z_i}=p_i-y_i,\qquad g=\frac1nX^T(p-y).$$

```python
p = sigmoid(X @ weights)
gradient = X.T @ (p - y) / len(y)
```

**RU:** Производная сигмоиды и производная перекрёстной энтропии сокращаются до p−y. Поэтому в этой формуле нельзя ещё раз умножать на p(1−p): это было бы лишним множителем.

**中文：** sigmoid与交叉熵的链式求导合并后就是p−y，不能再额外乘一次sigmoid导数。`X.T`为9×460，乘长度460的误差得到长度9的梯度。

### 4.5. Градиентный спуск — 为什么减去梯度

$$\theta_{t+1}=\theta_t-\alpha g_t.$$

```python
direction = gradient
candidate = weights - step * direction
```

**RU:** Градиент показывает направление наибольшего роста потерь. Для минимизации движение выполняется в противоположную сторону. Используется весь обучающий набор, поэтому это пакетный, а не стохастический градиентный спуск.

**中文：** 梯度指向损失增长最快的方向，所以减去梯度。每步使用全部训练样本，是批量梯度下降，不是随机梯度下降。初始权重为0意味着初始预测概率全为0.5。

### 4.6. Метод Ньютона — Hessian与线性方程

$$H=\frac1nX^T\operatorname{diag}(p_i(1-p_i))X,$$
$$H\delta=g,\qquad\theta_{t+1}=\theta_t-\alpha\delta.$$

```python
hessian = (X.T * (p * (1 - p))) @ X / len(y)
direction = np.linalg.solve(hessian + 1e-8 * np.eye(X.shape[1]), gradient)
```

**RU:** Умножение `X.T * (p*(1-p))` масштабирует столбцы Xᵀ и заменяет умножение на диагональную матрицу. Размер Гессиана равен 9×9. Решать систему устойчивее и дешевле, чем явно вычислять обратную матрицу.

**中文：** 广播运算按样本权重缩放X转置的各列，相当于乘对角矩阵，但不必创建460×460的大矩阵。Hessian只有9×9。`solve`是NumPy的通用线性代数功能，不是现成机器学习模型。

**RU:** Добавка 10⁻⁸I защищает решение от вырожденности. Она не добавляется к функции потерь и градиенту, поэтому это численная стабилизация шага, а не полноценная L2-регуляризация модели.

**中文：** 这个很小的对角项只稳定求解过程。真正L2正则化需要同时修改目标函数和梯度，不能把当前实现说成“带L2正则的逻辑回归”。

```python
while log_loss(y, X @ candidate) > history[-1] + 1e-12:
    step *= 0.5
```

**RU:** Если шаг Ньютона увеличивает потери, он уменьшается вдвое. Малый допуск учитывает погрешность вычислений. Значение α в двух методах масштабирует разные направления.

**中文：** 牛顿步过大可能让损失升高，因此不断折半。两种方法即使学习率相同，实际移动方向与距离也不相同。代码没有提前停止，执行指定迭代次数；折半是步长保护，不是减少训练迭代。

### 4.7. Порог и метрики — 分类与评价

```python
predicted = sigmoid(X @ weights) >= 0.5
tp = int(np.sum((y == 1) & (predicted == 1)))
```

**RU:** Порог переводит вероятность в класс. Здесь `&` — поэлементное логическое «и», а не обычный Python `and`. Положительный класс обозначает диабет.

**中文：** 阈值把概率转成布尔类别。NumPy数组要用 `&`逐元素与，并加括号，不能用Python的`and`。

| 指标 / Метрика | 公式 | 代码表达 | 含义 |
|---|---|---|---|
| Доля верных / Accuracy | $(TP+TN)/N$ | `(tp + tn) / len(y)` | 整体预测正确比例 |
| Точность / Precision | $TP/(TP+FP)$ | `tp / (tp + fp)` | 预测阳性中真的阳性占比 |
| Полнота / Recall | $TP/(TP+FN)$ | `tp / (tp + fn)` | 真实阳性中检出的比例 |
| F1-мера | $2TP/(2TP+FP+FN)$ | `2 * tp / (2 * tp + fp + fn)` | precision与recall的调和平均 |

**RU:** Accuracy и precision — разные метрики. При дисбалансе классов высокая доля верных ответов не гарантирует обнаружение положительных объектов.

**中文：** 不要混淆accuracy（准确率）和precision（精确率）。全预测0就有64.94%准确率，但召回率和F1都为0。

## 7. Вопросы преподавателя — 常见追问

**Почему логистическая регрессия, если задача классификации? 为什么叫回归？**

RU: Линейной функцией описываются логарифмические шансы. После сигмоиды получается вероятность, а после порога — класс.

中文：回归的是log-odds的线性关系；经过sigmoid得到概率，再通过阈值得到类别。

**Почему не среднеквадратичная ошибка? 为什么不用MSE？**

RU: Перекрёстная энтропия соответствует правдоподобию Бернулли. Её градиент имеет простой вид, а целевая функция логистической регрессии выпукла по весам.

中文：交叉熵来自伯努利最大似然，有简洁梯度；未正则化逻辑回归的该损失对参数是凸函数。凸性不等于任意步长都能稳定收敛。

**Почему не заполнить пропуски до разделения? 为什么不能先填补再划分？**

RU: Тогда медиана использовала бы сведения из тестовых объектов. Параметры предобработки должны быть частью обучаемой процедуры.

中文：那样中位数会包含测试数据的信息。预处理参数同样属于需要从训练集学习的部分。

**Почему не выбрать строку с максимальной тестовой F1? 为什么不选测试F1最高的？**

RU: Тест нужен для оценки, а не для настройки. Если выбирать по нему, оценка становится оптимистичной и перестаёт отражать независимую проверку.

中文：测试集用于评价，不用于调整。根据测试挑最好配置会造成选择偏差。

**Почему больше итераций не всегда лучше? 为什么训练更久F1不一定更好？**

RU: Минимизируются обучающие потери, а F1 измеряется на другой выборке после порогового решения. Эти критерии различаются.

中文：优化的是训练交叉熵，观察的是另一数据集上的离散F1，两者不是同一个目标。

**Это регуляризация? 少迭代和Hessian阻尼算正则化吗？**

RU: Явного штрафа L1 или L2 нет. Ограниченное обучение может давать эффект неявной регуляризации, а диагональная добавка стабилизирует вычисление шага.

中文：没有显式L1/L2罚项。有限迭代可以有隐式正则效果；对角项是数值稳定措施，概念不要混用。

**Что означает положительный коэффициент? 正权重如何解释？**

RU: При неизменных остальных признаках увеличение данного стандартизованного признака повышает логарифмические шансы класса 1. exp(w) — множитель шансов на один обучающий стандартный масштаб.

中文：其他特征不变时，标准化特征增加使正类log-odds增加。exp(w)是赔率倍数，不是概率倍数，也不是因果效应。

**Есть ли готовая модель в реализации? 是否偷偷用了现成模型？**

中文：没有。概率、损失、导数、训练循环和指标都手写；线性方程求解属于允许的NumPy基础操作。
