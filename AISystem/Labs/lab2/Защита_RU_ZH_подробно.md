## 4. 第二块 sigmoid 将线性输出转换为概率

**代码位置：** `sigmoid`，15–19行。**报告对应：** «ОПИСАНИЕ МЕТОДА»。

```python
def sigmoid(z):
    z = np.asarray(z, dtype=float)
    e = np.exp(-np.abs(z))
    return np.where(z >= 0, 1 / (1 + e), e / (1 + e))
```

### 4.1 数学含义

$$z_i=b+x_i^Tw,\qquad p_i=\sigma(z_i)=\frac1{1+e^{-z_i}}.$$

`z`是logit，即线性组合，可以取任意实数；`p`是模型估计的正类概率。例：z=0时p=0.5；z=2时p≈0.8808；z=−2时p≈0.1192。函数本身不使用标签，也不更新权重。

### 4.2 为什么不是直接写普通sigmoid

直接计算`np.exp(-z)`，当z=−1000时需要算exp(1000)，会溢出。代码令`e=exp(-abs(z))`，指数参数始终非正：

$$\sigma(z)=\begin{cases}
1/(1+e^{-z}),&z\ge0,\\
e^z/(1+e^z),&z<0.
\end{cases}$$

两种表达式完全等价。`np.where`按每个元素的符号选择分支；它会先求出两个分支，所以不能仅把不安全的指数挪到其中一个分支里。`np.asarray(...,dtype=float)`统一输入数组和浮点类型。

**输入与输出：** 输入长度n的z数组，返回同样长度n的概率数组。理论上有限z时概率严格在0和1之间；浮点极端值可能舍入成0或1，这正是损失函数也要稳定实现的原因。

**RU：** Сигмоида переводит линейный предиктор в вероятность. Я использую две равносильные формы, чтобы экспонента не получала большого положительного аргумента. Размер выходного вектора совпадает с размером входного.

**追问：为什么叫逻辑回归？** 因为线性的量是对数赔率：

$$\log\frac{p_i}{1-p_i}=b+x_i^Tw.$$

**RU：** Линейно моделируются логарифмические шансы. Сигмоида даёт вероятность, а порог превращает её в класс.

## 5. 第三块 log_loss 训练究竟在最小化什么

**代码位置：** `log_loss`，22–24行。**报告对应：** «Функция потерь и оптимизация»。

```python
def log_loss(y, z):
    return float(np.mean(np.logaddexp(0, z) - y * z))
```

### 5.1 从伯努利分布到交叉熵

标签只有0和1，因此单样本概率可写为：

$$P(y_i\mid x_i)=p_i^{y_i}(1-p_i)^{1-y_i}.$$

假设样本条件独立，总似然为乘积。取对数、加负号并除以n，最大化似然就变成最小化平均负对数似然：

$$L=-\frac1n\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].$$

当y=1，损失是−log(p)；当y=0，是−log(1−p)。例如真实正类但模型给p=0.01，损失约4.605；若给p=0.9，损失约0.105。损失惩罚的是概率错误程度，不只是分类对错。

### 5.2 代码的等价公式

利用：

$$\log p=z-\log(1+e^z),\qquad\log(1-p)=-\log(1+e^z),$$

得到：

$$L=\frac1n\sum_i\left[\log(1+e^{z_i})-y_i z_i\right].$$

`np.logaddexp(0,z)`稳定计算log(exp(0)+exp(z))，即log(1+exp(z))；`y*z`逐元素相乘，`mean`对样本求平均，`float`将NumPy标量转成Python浮点值。

**特别注意：** 函数的第二个参数是z，不是p。正确调用是`log_loss(y, X @ weights)`，不能把sigmoid后的概率传进去。

### 5.3 与报告数字的对应

初始权重全0，z全0、p全0.5，平均损失为ln2≈0.693147，与初始类别比例无关。所选配置在460条训练数据上训练100次后损失为0.581274；最终在614条开发数据上重训后，154条测试数据的损失为0.596365。这三个数字对应不同阶段，不能混为一谈。

**RU：** Функция потерь — средняя отрицательная логарифмическая правдоподобность Бернулли. В коде она вычисляется по логитам через logaddexp, что избегает прямого вычисления log(0). При нулевых весах начальные потери равны ln 2.

## 6. 第四块 split 分层划分的每一步

**代码位置：** `split`，27–35行。**报告对应：** «Предварительная обработка и разбиение»。

```python
def split(indices, y, fraction, rng):
    train, test = [], []
    for label in (0, 1):
        group = rng.permutation(indices[y[indices] == label])
        n = round(len(group) * fraction)
        test.extend(group[:n])
        train.extend(group[n:])
    return rng.permutation(train), rng.permutation(test)
```

| 表达式 | 含义 |
|---|---|
| `indices` | 本次要划分的原始行号；第二次调用只传开发集行号 |
| `y[indices] == label` | 在这些行里找到当前类别 |
| `indices[...]` | 按布尔掩码取该类原始行号 |
| `rng.permutation(...)` | 不重复地随机打乱顺序 |
| `round(len(group)*fraction)` | 当前类别留出数量 |
| `group[:n]` | 留出部分，不含位置n |
| `group[n:]` | 剩余部分 |
| `.extend(...)` | 把多个行号加入列表；不是把整组当一个元素 |
| 最后的两次`permutation` | 混合两个类别，避免输出按类别分块 |

函数返回的是**行号**，不是数据矩阵；返回值为“剩余部分、留出部分”。内部变量名`test`只是留出部分的名字，第二次调用时它实际成为验证集。

### 6.1 为什么得到460/154/154

第一轮留出20%：负类500×0.2=100，正类268×0.2=53.6四舍五入为54。测试共154，开发集负类400、正类214，共614。

第二轮从开发集中留出25%：负类400×0.25=100，正类214×0.25=53.5在当前舍入规则下为54。验证共154，训练剩余负类300、正类160，共460。

| 分区 | 负类0 | 正类1 | 总计 |
|---|---:|---:|---:|
| 训练 | 300 | 160 | 460 |
| 验证 | 100 | 54 | 154 |
| 测试 | 100 | 54 | 154 |
| 开发集＝训练＋验证 | 400 | 214 | 614 |

Python的`round`遇到精确半整数使用“最接近的偶数”，不是所有情况都传统四舍五入；本例53.5→54。整体约60/20/20，因逐类取整并不完全精确。

**RU：** Разбиение выполняется отдельно для каждого класса. Функция возвращает исходные индексы объектов. Сначала выделяется тестовая часть, затем проверочная из оставшихся данных. Получаются 460 обучающих, 154 проверочных и 154 тестовых объекта.

### 7.4 标准化

$$\mu_j=\frac1n\sum_i\widetilde x_{ij},\quad
s_j=\sqrt{\frac1n\sum_i(\widetilde x_{ij}-\mu_j)^2},\quad
x'_{ij}=\frac{\widetilde x_{ij}-\mu_j}{s_j}.$$

$\widetilde x$表示填补后的特征。`ddof=0`使用总体式分母n；标准差0改成1避免除零。训练集转换后各列均值约0、非恒定列标准差约1；测试集不一定均值0，因为它使用训练参数。

Pandas会按Series的列名对齐计算，不是按任意顺序相减。完成带列名的处理后，`to_numpy()`转为NumPy矩阵供训练使用。

## 9. 第七块 梯度公式的推导与矩阵尺寸

**核心代码：** `gradient = X.T @ (p - y) / len(y)`。

先对单样本稳定损失求导：

$$\ell_i(z_i)=\log(1+e^{z_i})-y_i z_i,$$

$$\frac{\partial\ell_i}{\partial z_i}=\frac{e^{z_i}}{1+e^{z_i}}-y_i=p_i-y_i.$$

由于$z_i=X_i^T\theta$：

$$\frac{\partial L}{\partial\theta_j}=\frac1n\sum_iX_{ij}(p_i-y_i),
\qquad g=\frac1nX^T(p-y).$$

因此不能在这行外面再乘一次p(1−p)，sigmoid的导数已经包含在推导中。

| 运算 | 形状 | 意义 |
|---|---|---|
| `X @ weights` | 长度460 | 每个样本的logit |
| `sigmoid(...)` | 长度460 | 正类概率 |
| `p - y` | 长度460 | 每样本的概率误差 |
| `X.T` | 9×460 | 把各样本的误差汇总到各参数 |
| `X.T @ (p-y)` | 长度9 | 各参数的总导数 |
| 除以`len(y)` | 长度9 | 平均损失的梯度 |

`@`是矩阵乘法；`*`是逐元素乘法。除以n与损失中的平均一致，也让学习率的尺度较少依赖样本数量。

**RU：** Производная потерь по логиту равна p−y. Умножение на Xᵀ суммирует вклад объектов для каждого коэффициента. Деление на число объектов соответствует средней функции потерь.

## 10. 第八块 梯度下降怎样更新权重

**代码位置：** 63行和68–69行。

```python
direction = gradient
step = rate
candidate = weights - step * direction
```

$$\theta_{t+1}=\theta_t-\alpha g_t.$$

梯度指向损失局部增长最快的方向，因此取负方向。每步使用全部460条训练数据，叫**批量梯度下降**；一次迭代是一次完整更新，不是仅处理一个样本。

小步长可能需要很多步；大步长可能导致震荡或增长。本实验网格中训练均得到有限损失，不能说已经实验发现了发散。当前gd分支没有回溯步长控制；损失有限也不等于每一步都严格下降。

### 10.1 用本实验第一步证明理解

训练集有160个正类，初始p=0.5。截距梯度是：

$$g_0=\frac1{460}\sum_i(0.5-y_i)=0.5-\frac{160}{460}=0.152173913.$$

学习率0.01时第一次截距更新：

$$b_1=0-0.01\times0.152173913=-0.001521739.$$

实际初始损失0.6931471806，更新一次后0.6913933158；100次后0.5812739568。截距先向负数移动，是因为训练负类较多，需要降低整体正类概率。

**RU：** На первом шаге все вероятности равны 0,5. Положительных объектов 160 из 460, поэтому градиент свободного члена равен 0,15217. При шаге 0,01 свободный член становится −0,00152, а потери уменьшаются.

## 11. 第九块 牛顿法的Hessian和方向

**代码位置：** 64–67行。**报告对应：** «Метод Ньютона»。

```python
if method == 'newton':
    hessian = (X.T * (p * (1 - p))) @ X / len(y)
    direction = np.linalg.solve(hessian + 1e-8 * np.eye(X.shape[1]), gradient)
```

### 11.1 数学推导

对梯度再求导，利用sigmoid导数：

$$\sigma'(z)=p(1-p),\qquad
H=\frac1nX^T D X,\qquad D=\operatorname{diag}(p_i(1-p_i)).$$

牛顿法在当前点用二次模型近似损失：

$$L(\theta+s)\approx L(\theta)+g^Ts+\tfrac12s^THs.$$

其近似最小点满足g+Hs=0。令Hδ=g，就有s=−δ，更新θ←θ−αδ。梯度下降只看一阶方向，牛顿法利用曲率调整各参数方向的尺度。

### 11.2 为什么没有创建460×460对角矩阵

`p*(1-p)`长度460；`X.T`为9×460。NumPy广播让这个向量乘到X转置的各列，等价于XᵀD；再乘460×9的X，得到9×9的Hessian。这样省去了显式创建大对角矩阵。

### 11.3 solve 与10⁻⁸I

`np.linalg.solve(H+εI,g)`解线性方程，不显式形成H的逆矩阵。ε=10⁻⁸给对角线加很小的数，可改善求解稳定性。NumPy线性代数是允许的基础工具，不是现成逻辑回归训练器。

这里只修改牛顿方向求解，不向损失和梯度加入λθ，所以不能说模型有显式L2正则化。

梯度下降一步主要成本约O(nd)；牛顿法约O(nd²+d³)，d在本实验包含截距等于9。牛顿法减少迭代次数，不代表任何维度、任何设备上总时间一定更短。当前代码没有计时比较。

**RU：** Метод Ньютона использует матрицу вторых производных. Она имеет размер 9×9. Диагональные веса объектов применяются через broadcasting, поэтому большая диагональная матрица не создаётся. Направление вычисляется решением системы, а маленькая диагональная добавка стабилизирует расчёт.

## 12. 第十块 牛顿步的回溯与训练结束

**代码位置：** 68–81行。

```python
step = rate
candidate = weights - step * direction
if method == 'newton':
    while log_loss(y, X @ candidate) > history[-1] + 1e-12:
        step *= 0.5
        candidate = weights - step * direction
        if step < 1e-12:
            candidate = weights.copy()
            break
weights = candidate
history.append(log_loss(y, X @ weights))
if not np.isfinite(history[-1]):
    raise FloatingPointError('Потери неограниченно растут: уменьшите шаг')
return weights, history
```

1. 从网格指定的rate开始，计算候选权重。
2. 如果候选损失比上一步大超过10⁻¹²，将step减半后重试。
3. 若step极小，保留原权重并退出本次步长搜索。
4. 接受权重，记录损失，检查是否有限。
5. 外层循环执行完规定次数，返回权重和损失历史。

`history[-1]`是当前已接受权重的损失；比较的是训练损失，没有调用验证或测试数据。容差10⁻¹²避免因浮点误差对微小增长无限重试。

**要区分：** `break`只退出内部`while`，不会退出外层`for`。代码仍执行iterations次；这不是基于梯度大小或验证损失的提前停止。这里是简单的损失非增长保护，不能称作实现了完整Armijo条件或所有数值问题的通用解决方案。

每轮外层更新都会把`step`重设为rate；某一轮折半得到的小步长不会自动成为下一轮初始步长。

**RU：** Если кандидат увеличивает обучающие потери, шаг Ньютона уменьшается вдвое. При слишком малом шаге сохраняются прежние веса. Это защита отдельного шага; заданное число внешних итераций не сокращается.

## 13. 第十一块 metrics 四项指标逐行解释

**代码位置：** 84–93行。**报告对应：** «Метрики и градиентный спуск»。

```python
tp = int(np.sum((y == 1) & (predicted == 1)))
tn = int(np.sum((y == 0) & (predicted == 0)))
fp = int(np.sum((y == 0) & (predicted == 1)))
fn = int(np.sum((y == 1) & (predicted == 0)))
return dict(accuracy=(tp + tn) / len(y), precision=tp / (tp + fp) if tp + fp else 0,
            recall=tp / (tp + fn) if tp + fn else 0,
            f1=2 * tp / (2 * tp + fp + fn) if 2 * tp + fp + fn else 0,
            tp=tp, tn=tn, fp=fp, fn=fn)
```

比较产生布尔数组，`&`逐元素求“与”；括号不能省略。`np.sum`把True按1计数，`int`将NumPy整数变成Python整数，便于JSON序列化。

`predicted`可以是布尔数组，因为True对应1、False对应0。该函数接收分类结果，而不是原始概率。

| 指标 | 中文理解 | 公式 | 最终测试计算 |
|---|---|---|---|
| accuracy | 全部样本中正确比例 | (TP+TN)/N | (32+84)/154=0.753247 |
| precision | 预测正类中真的正类比例 | TP/(TP+FP) | 32/48=0.666667 |
| recall | 真正正类中检出的比例 | TP/(TP+FN) | 32/54=0.592593 |
| F1 | 精确率和召回率的调和平均 | 2TP/(2TP+FP+FN) | 64/102=0.627451 |

F1也可写成2PR/(P+R)，代码直接用计数计算，少做一次间接除法。三元表达式`... if denominator else 0`规定分母0时返回0，避免异常。

## 16. 第十四块 main 的40组实验

**代码位置：** 119–132行。**报告对应：** «План исследования», 两张完整20行结果表。

```python
rows, curves = [], {}
for method in ('gd', 'newton'):
    for rate in RATES:
        for iterations in STEPS:
            weights, history = fit(Xtrain, y[train], rate, iterations, method)
            row = dict(method=method, rate=rate, iterations=iterations, train_loss=history[-1])
            for name, X, target in [('val', Xval, y[validation]), ('test', Xtest, y[test])]:
                row.update({f'{name}_{k}': v for k, v in metrics(target, sigmoid(X @ weights) >= 0.5).items()})
                row[f'{name}_loss'] = log_loss(target, X @ weights)
            rows.append(row)
            if iterations == max(STEPS):
                curves[(method, rate)] = history
results = pd.DataFrame(rows)
results.to_csv(out / 'hyperparameter_results.csv', index=False)
```

`rows`是40个结果字典的列表；`curves`是以(method,rate)二元组为键的字典，存每种方法每个步长的2000步损失曲线，共8条。

每组在相同训练矩阵上从零权重训练；验证、测试划分和阈值完全相同。差别只有方法、学习率和迭代次数。

内部两次评价分别命名val和test。`metrics(...).items()`枚举键值，如`('f1',0.627...)`；字典推导式加前缀，形成`val_f1`、`test_f1`。`row.update`把这些键值并入本组结果。这样同一函数不用写两遍。

预测表达式`sigmoid(X @ weights) >= 0.5`返回布尔类别。阈值大于等于意味着p恰好0.5归正类；阈值比较仅用于评价，不进入梯度求导。

`iterations==max(STEPS)`只决定是否保存完整曲线；不会减少训练次数。5、20、100、500、2000步的模型都分别重新训练，而不是缓存大模型的中间权重用于全部评价。

**RU：** Три вложенных цикла дают 40 конфигураций. Для каждой сохраняются обучающие потери, проверочные и тестовые метрики. Порог и разбиение одинаковы, а веса каждый раз инициализируются заново. Истории по 2000 итераций сохраняются для графика сходимости.

```python
              'prediction': (probabilities >= 0.5).astype(int)}).to_csv(out / 'test_predictions.csv', index=False)
pd.DataFrame({'feature': ['intercept'] + FEATURES, 'coefficient': weights,
              'odds_ratio': np.exp(weights)}).to_csv(out / 'coefficients.csv', index=False)
np.savez(out / 'model.npz', weights=weights, medians=parameters[0].to_numpy(),
         means=parameters[1].to_numpy(), scales=parameters[2].to_numpy(), features=np.array(FEATURES))
```

`test_predictions.csv`保存原始行号、真实标签、概率和0/1预测。`astype(int)`把True/False转为1/0，`index=False`避免把DataFrame附加索引当作额外列保存。

`coefficients.csv`第一行是截距，然后8个特征；与`prepare`设计矩阵的列顺序一致。`np.exp(weights)`将log-odds系数转换为赔率倍数。

$$\log\frac{p}{1-p}=b+\sum_jw_jx'_j.$$

其余特征固定，x′ⱼ增加1，赔率乘exp(wⱼ)，对应原始特征增加一个开发集标准差，不是原始单位增加1。截距的exp(b)表示各标准化特征为0时的基准赔率，不能解释为“截距特征增加一个标准差”。

实际最终Glucose系数约0.201832，exp(w)≈1.223643：在当前拟合模型里，其他输入不变，血糖提高一个开发集标准差，正类赔率约乘1.2236。概率不会普遍乘1.2236，相关关系也不能解释成因果。

所选配置尚未完全收敛，这些系数尤其不能作为可靠的医学因果估计或已证明的独立风险因素。

### 19.1 为什么不能只保存权重

若另一个程序使用不同中位数或标准差，同一原始样本会变成不同输入，权重就失去原训练含义。`.npz`因此保存weights、medians、means、scales和features，足以复用数值变换与预测；阈值0.5由程序约定。

**RU：** Сохраняется не только вектор весов, но и параметры заполнения и стандартизации. Они нужны для применения модели к новым объектам. Экспонента коэффициента показывает множитель шансов при изменении стандартизованного признака на единицу.

## 24. test_logistic_regression.py 六类检查在证明什么

当前六项测试已重新运行并通过。测试不能证明模型一定泛化良好，证明的是实现中的部分关键性质。

| 测试 | 具体检查 | 答辩意义 |
|---|---|---|
| `test_sigmoid` | ±1000、0下sigmoid稳定；自信错误logits损失1000 | 极端输入没有指数溢出 |
| `test_derivatives` | 用中心有限差分对照梯度和Hessian | 手写导数与数值变化相符 |
| `test_optimizers` | 合成数据上两种方法权重接近；检查损失；Newton大步长100保护 | 两种实现优化同一目标，回溯起作用 |
| `test_metrics` | 人工混淆矩阵应产生0.5；无预测正类时precision=0 | 指标公式和分母处理正确 |
| `test_preprocessing` | 给新数据应用预处理不会改旧参数；训练均值约0 | 变换不会偷偷重拟合 |
| `test_partition` | 不重叠、全部覆盖、固定种子相同、测试数154 | 划分的完整性和可复现性 |

中心差分公式：

$$g_j\approx\frac{L(\theta+\varepsilon e_j)-L(\theta-\varepsilon e_j)}{2\varepsilon},\qquad\varepsilon=10^{-5}.$$

对梯度差分可验证Hessian每列。`np.testing.assert_allclose`检查误差在容差内，而不是要求浮点完全逐位相同。

优化器测试用合成数据，是因为不能仅凭Pima某次accuracy“看起来合理”来证明导数或优化实现正确。`unittest`来自标准库，符合依赖限制。

**RU：** Производные проверяются центральными конечными разностями. На синтетическом наборе два оптимизатора сходятся к близким весам. Также проверены крайние значения, метрики, предобработка и разбиение. Это проверка вычислений, а не доказательство универсального качества модели.

### 25.1 为什么用验证集F1，不用accuracy

**RU：** Классы несбалансированы: 500 отрицательных и 268 положительных объектов. Высокая доля верных ответов может получаться за счёт большинства. F1 учитывает и точность положительного прогноза, и полноту; этот критерий был зафиксирован для выбора параметров.

**中文：** 类别不平衡，多数类可获得较高accuracy。F1同时考虑正类precision和recall，是本实验预先选定的选参指标；不是所有应用都必须以F1为最佳指标。

**RU：** Значение 0,7987 относится к другой конфигурации сетки. Конфигурация выбиралась по проверочной F1, а не по тестовой доле верных ответов. В заключении приведён результат выбранной и переобученной модели.

**中文：** 不能把网格中测试最好的指标拿来冒充最终验证选中模型的成绩。报告给的是按既定规则选出的最终模型。

### 25.3 最佳验证模型尚未收敛是不是错误

**RU：** Нет, потому что критерий выбора — качество на проверке, а не минимум обучающих потерь. Ограниченный бюджет шагов может изменять обобщение. Но преимущество по F1 мало и не доказано статистически.

**中文：** 两个目标不同，不是实现错误；少迭代可能有隐式正则效果，但没有证明这种微小验证优势稳定存在。

### 25.4 为什么各小学习率模型分类指标一开始很像

**RU：** Небольшие веса могут давать похожие знаки логитов, хотя вероятности близки к 0,5 и продолжают изменяться. Метрики используют классы после порога и не показывают всю динамику вероятностей.

**中文：** 阈值分类只取logit符号，权重很小也可能给相同类别；损失还会随概率变化。分类平台不能单独判定训练停止。

### 25.5 loss越小是不是F1越大

**RU：** Нет. Потери оценивают вероятности, а F1 — пороговые ответы; кроме того, обучение и проверка используют разные объекты.

**中文：** 连续概率误差和阈值分类指标不同，且数据集也不同，所以没有必然单调关系。

### 25.6 用了np.linalg.solve为什么还叫从零

**RU：** Я самостоятельно задаю модель, потери, производные и цикл обучения. solve выполняет только базовую операцию линейной алгебры внутри моего метода Ньютона. Готовой библиотечной модели нет.

**中文：** 任务允许NumPy，线性方程求解是基础操作；建模和优化逻辑仍是自己实现。

### 25.7 为什么不是随机梯度下降

**RU：** В каждом шаге градиент вычисляется по всей обучающей матрице. Поэтому реализован пакетный градиентный спуск. Перемешивание объектов при разбиении не превращает его в стохастический.

**中文：** 是否SGD由每次更新使用多少样本决定，与划分时是否打乱数据不同。

### 25.8 为什么不能训练前对整个表标准化

**RU：** Среднее и стандартное отклонение тогда учитывали бы тестовые объекты. Эти параметры должны оцениваться только по части, доступной при обучении.

**中文：** 标准化也是需要从训练集估计的变换；不能利用测试统计。描述性统计只用于报告，不输入这些参数。

### 25.9 降低阈值会怎样

**RU：** На фиксированных вероятностях снижение порога не уменьшает число положительных прогнозов и обычно повышает или сохраняет полноту. Точность и F1 могут как улучшиться, так и ухудшиться. В этой работе порог не настраивался и равен 0,5.

**中文：** 固定概率下，阈值降低使预测正类增多，recall不下降；precision和F1不保证单调变化。若以后优化阈值，应在验证数据上做，并重新独立评估。

### 25.10 逻辑回归的损失是凸的，为什么还要讨论收敛

**RU：** Выпуклость описывает форму целевой функции, но не гарантирует устойчивость произвольного шага или достаточность малого числа итераций. При недостаточном ранге или разделимых данных также нужны дополнительные условия для конечного единственного решения.

**中文：** 凸性不保证任意学习率稳定，也不保证5步收敛；有限唯一最优解还依赖数据条件，不能只说“凸所以总能训练成功”。

### 25.11 为什么重训后同样F1而loss不同

**RU：** На разработке изменились веса и параметры предобработки. Вероятности изменились, хотя суммарные классификационные показатели остались такими же. Log loss учитывает степень уверенности.

**中文：** 重新拟合了数值变换和权重，概率不同；分类计数相同可以产生同样F1。

### 25.12 这个实验的改进方向有哪些

**RU：** Можно проверить устойчивость через стратифицированную перекрёстную проверку, исследовать регуляризацию, более информативную обработку пропусков и порог. Каждый дополнительный параметр следует выбирать без использования теста.

### 第二段 清洗与划分

**中文提纲：** 460/154/154 → 五列0 → 训练参数 → 标准化 → 截距。

### 第三段 模型与损失

**RU：** Линейный предиктор вычисляется произведением X на вектор весов. Сигмоида переводит его в вероятность класса 1. Средняя перекрёстная энтропия соответствует отрицательному логарифму правдоподобия Бернулли. Для устойчивости сигмоида использует две равносильные формы, а потери вычисляются через logaddexp по логитам.

**中文提纲：** z=Xθ → sigmoid → 伯努利负对数似然 → 稳定计算。

### 第四段 优化实现

**RU：** Градиент равен Xᵀ(p−y), делённому на число объектов. В градиентном спуске он вычитается с коэффициентом обучения. Метод Ньютона дополнительно строит матрицу Гессе и решает систему для направления. Если новый шаг увеличивает потери, его величина уменьшается вдвое. Оба метода выполняют заданное число итераций и начинают с нулевых весов.

**中文提纲：** p−y梯度 → gd负梯度 → Newton曲率与solve → 折半保护 → 统一初始化。

### 第五段 参数研究与结果

**RU：** Исследованы два метода, четыре коэффициента обучения и пять значений числа итераций — всего 40 комбинаций. Для каждой рассчитаны доля верных ответов, точность, полнота и F1. Параметры выбираются по проверочной F1; тестовые показатели в выборе не участвуют. Выбран градиентный спуск с шагом 0,01 и 100 итерациями. После переобучения на 614 объектах тестовая доля верных ответов равна 0,7532, точность — 0,6667, полнота — 0,5926, F1 — 0,6275.

**中文提纲：** 40组合 → 四指标 → 验证选参 → gd0.01/100 → 614重训 → 最终成绩。

### 第六段 结论与限制

**RU：** Ньютон быстрее достигает близкого минимума по числу итераций, но это не гарантирует максимальную проверочную F1. Выбранный вариант ещё не полностью сошёлся, а преимущество на проверке небольшое. Результат относится к одной выборке и одному разбиению. Для более надёжного вывода нужны перекрёстная проверка и новые независимые данные. Корректность ключевых вычислений проверена шестью тестами.

**中文提纲：** 收敛速度≠泛化F1 → 优势小 → 单次划分局限 → 6项数值检查。
