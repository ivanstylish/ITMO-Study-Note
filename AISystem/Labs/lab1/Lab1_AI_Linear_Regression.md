## 1. 实验到底在做什么？ / Что делает лабораторная работа?

**中文**

任务是根据学生的若干特征预测连续变量
`Performance Index`。这是一个**监督学习中的回归问题**。程序没有调用

程序建立三个模型：

-   模型

**Русский**

Строятся три модели с разными наборами признаков, а качество
сравнивается по **R², RMSE и MAE** на тестовой выборке.

## 2. 多元线性回归 / Множественная линейная регрессия

### 2.1 核心公式 / Основная формула

\[ `\hat `{=tex}y = `\theta`{=tex}\_0 +
`\theta`{=tex}\_1x_1+`\theta`{=tex}\_2x_2+`\cdots`{=tex}+`\theta`{=tex}\_px_p
\]

**中文**

-   (x_1,`\dots`{=tex},x_p)：输入特征；
-   (`\theta`{=tex}\_1,`\dots`{=tex},`\theta`{=tex}\_p)：每个特征的权重/回归系数；
-   (`\theta`{=tex}\_0)：截距；
-   (`\hat `{=tex}y)：模型预测值；
-   (y)：真实值。

例如，若只使用学习时间和过去成绩：

\[
`\hat `{=tex}y=`\theta`{=tex}\_0+`\theta`{=tex}\_1`\cdot `{=tex}Hours+`\theta`{=tex}\_2`\cdot `{=tex}PreviousScores
\]

线性回归的"线性"主要是指**模型对参数 (`\theta`{=tex}) 是线性的**。

**Русский**

-   (x_j) --- признаки;
-   (`\theta`{=tex}\_j) --- коэффициенты модели;
-   (`\theta`{=tex}\_0) --- свободный член;
-   (`\hat `{=tex}y) --- прогноз;
-   \(y\) --- фактическое значение.

Коэффициент показывает, как изменяется прогноз при изменении
соответствующего признака при фиксированных остальных признаках.

### 2.2 矩阵形式 / Матричная форма

\[ `\hat{\mathbf y}`{=tex}=X`\theta`{=tex} \]

代码：

``` python
error = x @ theta - y
```

`@` 是矩阵乘法。若有 (n) 个样本、(p) 个特征，则加入截距列后：

\[ X`\in`{=tex}`\mathbb{R}`{=tex}\^{n`\times`{=tex}(p+1)},`\qquad`{=tex}
`\theta`{=tex}`\in`{=tex}`\mathbb{R}`{=tex}\^{p+1},`\qquad`{=tex}
X`\theta`{=tex}`\in`{=tex}`\mathbb{R}`{=tex}\^{n} \]

------------------------------------------------------------------------

## 3. 为什么添加全 1 列？ / Зачем добавляется столбец единиц?

代码：

``` python
x = np.column_stack([np.ones(len(x)), x])
theta = np.zeros(x.shape[1])
```

**中文**

全 1 列对应截距 (`\theta`{=tex}\_0)。因为：

\[
`\theta`{=tex}\_0`\cdot1`{=tex}+`\theta`{=tex}\_1x_1+`\cdots`{=tex}+`\theta`{=tex}\_px_p
\]

这样可以把截距和其他系数统一写成矩阵乘法 (X`\theta`{=tex})。

如果没有这一列，模型会被强制经过原点。

**Русский**

Столбец единиц нужен для обучения свободного члена (`\theta`{=tex}\_0).
Благодаря ему весь прогноз можно записать одной матричной операцией
(X`\theta`{=tex}). Без свободного члена модель была бы принудительно
ограничена прохождением через начало координат.

------------------------------------------------------------------------

## 4. 损失函数 MSE / Функция потерь MSE

程序训练时最小化均方误差：

\[
J(`\theta`{=tex})=`\frac{1}{n}`{=tex}`\sum`{=tex}\_{i=1}^{n}(`\hat `{=tex}y_i-y_i)^2
\]

矩阵形式：

\[
J(`\theta`{=tex})=`\frac{1}{n}`{=tex}(X`\theta`{=tex}-y)\^T(X`\theta`{=tex}-y)
\]

代码首先计算：

``` python
error = x @ theta - y
```

即：

\[ e=X`\theta`{=tex}-y \]

**为什么平方？ / Почему квадрат ошибки?**

中文：平方后正负误差不会抵消，而且大误差受到更强惩罚；同时该函数可导，便于使用梯度下降。

Русский: квадрат не позволяет положительным и отрицательным ошибкам
взаимно уничтожаться, сильнее штрафует большие ошибки и даёт удобную
дифференцируемую функцию.

------------------------------------------------------------------------

## 5. 梯度下降------最重要部分 / Градиентный спуск --- главная часть

### 5.1 梯度 / Градиент

对于

\[ J(`\theta`{=tex})=`\frac`{=tex}1n\|X`\theta`{=tex}-y\|\^2 \]

梯度为：

\[
`\nabla `{=tex}J(`\theta`{=tex})=`\frac{2}{n}`{=tex}X\^T(X`\theta`{=tex}-y)
\]

代码完全对应：

``` python
error = x @ theta - y
gradient = 2 / len(y) * (x.T @ error)
```

其中：

-   `x.T` = (X\^T)
-   `error` = (X`\theta`{=tex}-y)
-   `2 / len(y)` = (2/n)

### 5.2 参数更新 / Обновление коэффициентов

\[ `\theta`{=tex}\^{(k+1)} =
`\theta`{=tex}^{(k)}-`\alpha`{=tex}`\nabla `{=tex}J(`\theta`{=tex}^{(k)})
\]

代码：

``` python
new_theta = theta - rate * gradient
```

这里 `rate = 0.05` 就是学习率：

\[ `\alpha=0.05`{=tex} \]

**中文理解：**
梯度指出函数增长最快的方向，所以为了让误差下降，要沿着**负梯度方向**更新。

**Русский:** градиент показывает направление наиболее быстрого роста
функции потерь, поэтому для минимизации параметры изменяются в
направлении **минус градиента**.

### 5.3 为什么叫"批量"梯度下降？ / Почему Batch Gradient Descent?

因为每次更新 (`\theta`{=tex}) 时都使用整个训练集：

\[ `\nabla `{=tex}J=`\frac`{=tex}2nX\^T(X`\theta`{=tex}-y) \]

不是每次只取一个样本，也不是随机取一个小批次。

-   Batch GD：整个训练集
-   SGD：通常一个随机样本
-   Mini-batch GD：一个小批次

## 6. 停止条件 / Критерий остановки

代码：

``` python
if np.max(np.abs(new_theta - theta)) < eps:
    break
```

其中：

\[
`\max`{=tex}\_j\|`\theta`{=tex}\_j\^{new}-`\theta`{=tex}\_j\^{old}\|\<`\varepsilon`{=tex}
\]

且：

\[ `\varepsilon=10`{=tex}\^{-10} \]

**中文**

如果所有参数的最大变化都已经非常小，就认为算法收敛。除此之外还有
`steps=30000`，防止算法一直运行。

**Русский**

Если максимальное изменение любого коэффициента становится меньше
(`\varepsilon`{=tex}), считается, что алгоритм сошёлся. Ограничение
`30000` итераций защищает от бесконечного обучения.

------------------------------------------------------------------------

## 7. 为什么必须标准化？ / Зачем нужна стандартизация?

代码：

``` python
mean, std = x_train.mean(axis=0), x_train.std(axis=0)
(x_train - mean) / std
```

公式：

\[ z=`\frac{x-\mu}{\sigma}`{=tex} \]

标准化后通常：

\[
`\mu`{=tex}\_z`\approx0`{=tex},`\qquad `{=tex}`\sigma`{=tex}\_z`\approx1`{=tex}
\]

**中文**

不同特征的量纲可能差很多。如果一个特征在 0--100，另一个在
0--1，梯度下降会在不同方向上尺度不一致，收敛可能更慢。标准化能让梯度下降更稳定、更容易选择学习率。

同时，本实验中标准化后的系数在同一模型内更适合比较相对大小。

**Русский**

Если признаки имеют разные масштабы, поверхность функции потерь
становится плохо обусловленной, и градиентный спуск может сходиться
медленнее. Стандартизация приводит признаки примерно к одинаковому
масштабу и облегчает обучение. После стандартизации модули коэффициентов
внутри одной модели также удобнее сравнивать.

### 非常重要：为什么只用训练集的均值和标准差？

程序先算：

``` python
mean, std = x_train.mean(axis=0), x_train.std(axis=0)
```

然后同一组 `mean/std` 同时处理 train 和 test。

原因是避免 **data leakage（数据泄漏）**。

测试集应该模拟模型从未见过的新数据。如果使用测试集自己的均值、标准差，就等于在训练/预处理阶段利用了测试集的信息。

**На русском:** параметры стандартизации вычисляются только по обучающей
выборке, чтобы тестовая выборка не передавала модели информацию заранее.
Это предотвращает **утечку данных**.

代码逻辑：

if numeric:

\[ Mode(x)=`\text{наиболее частая категория}`{=tex} \]

中文：使用出现次数最多的类别补全。

Русский: пропуск заменяется наиболее часто встречающейся категорией.

本实验原始数据实际没有缺失值，但代码实现了这一处理流程。

## 9. 类别变量编码 / Кодирование категориальных признаков

原始变量：

`Extracurricular Activities = Yes / No`

机器学习公式需要数值，因此程序使用：

``` python
pd.get_dummies(part, drop_first=True, dtype=float)
```

对于二分类变量，可以理解为：

\[ No`\rightarrow0`{=tex},`\qquad `{=tex}Yes`\rightarrow1`{=tex} \]

`drop_first=True` 删除一个基准类别，避免产生完全线性相关的冗余虚拟变量。

**Русский**

Категориальный признак преобразуется в числовой dummy-признак. Для двух
категорий достаточно одного индикатора, например `No=0`, `Yes=1`.
`drop_first=True` удаляет избыточную базовую категорию.

rng = np.random.default_rng(SEED)

## 11. R² 决定系数 / Коэффициент детерминации R²

代码：

``` python
sse = np.sum(residual**2)
r2 = 1 - sse / np.sum((y - y.mean()) ** 2)
```

公式：

\[ R\^2=1-`\frac{\sum_i(y_i-\hat y_i)^2}`{=tex}
{`\sum`{=tex}\_i(y_i-`\bar `{=tex}y)\^2} \]

记：

\[ SSE=`\sum`{=tex}\_i(y_i-`\hat `{=tex}y_i)\^2 \]

\[ SST=`\sum`{=tex}\_i(y_i-`\bar `{=tex}y)\^2 \]

所以：

\[ R\^2=1-`\frac{SSE}{SST}`{=tex} \]

### 如何理解？

-   (R\^2=1)：完美预测；
-   (R\^2) 越接近 1，一般说明拟合越好；
-   (R\^2=0)：效果相当于总是预测测试集真实值的均值这一基准；
-   (R\^2\<0)：甚至比该均值基准更差。

本实验测试结果：

  模型           R²
  -------- --------
  模型 1     0.1468
  模型 2     0.8377
  模型 3     0.9886

模型 3 的 (R\^2=0.9886)，表示在该测试集上，按 R²
的定义，相对于均值基准，它解释了约 98.86% 的目标变量变异。

**Русский**

(R\^2) сравнивает ошибку модели с разбросом целевой переменной
относительно её среднего. Чем ближе значение к 1, тем большую долю
вариации целевой переменной описывает модель.

------------------------------------------------------------------------

## 12. RMSE / Среднеквадратичная ошибка

公式：

\[ RMSE= `\sqrt{\frac1n\sum_{i=1}^n(y_i-\hat y_i)^2}`{=tex} \]

代码：

``` python
np.sqrt(np.mean(residual**2))
```

**中文**

RMSE 和目标变量单位相同。本实验目标是 Performance Index，所以
RMSE=2.0648 可以理解为典型误差尺度大约是 2
个指数点。由于误差被平方，大误差会受到更大惩罚。

**Русский**

RMSE измеряется в тех же единицах, что и целевая переменная. Из-за
возведения ошибок в квадрат крупные ошибки влияют на RMSE сильнее.

------------------------------------------------------------------------

## 13. MAE / Средняя абсолютная ошибка

公式：

\[ MAE=`\frac`{=tex}1n`\sum`{=tex}\_{i=1}\^n\|y_i-`\hat `{=tex}y_i\| \]

代码：

``` python
np.mean(np.abs(residual))
```

模型 3：

\[ MAE=1.6398 \]

**中文**

表示预测值与真实值之间的平均绝对差约为 1.64 个 Performance Index 点。

**Русский**

MAE показывает среднюю абсолютную величину ошибки. Для третьей модели
прогноз отличается от фактического значения в среднем примерно на 1.64
пункта индекса.

### RMSE 与 MAE 的区别 / Разница RMSE и MAE

RMSE 对大误差更加敏感；MAE 更直观、对异常大误差没有平方惩罚。

------------------------------------------------------------------------

## 14. 相关系数 / Коэффициент корреляции

报告中的相关矩阵用于观察两个变量之间的**线性关系**。Pearson
相关系数可写为：

\[ r\_{xy}= `\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}`{=tex}
{`\sqrt{\sum_i(x_i-\bar x)^2}`{=tex}
`\sqrt{\sum_i(y_i-\bar y)^2}`{=tex}} \]

范围：

\[ -1`\le `{=tex}r`\le1`{=tex} \]

-   (r`\approx1`{=tex})：强正线性相关
-   (r`\approx-1`{=tex})：强负线性相关
-   (r`\approx0`{=tex})：线性相关弱

报告中：

\[ corr(PreviousScores,PerformanceIndex)`\approx0.915`{=tex} \]

\[ corr(HoursStudied,PerformanceIndex)`\approx0.375`{=tex} \]

所以 `Previous Scores` 与目标的线性关系明显更强。

**注意 / Важно:** 相关不等于因果。\
**Корреляция не означает причинность.**

## 15. 合成特征 Study Efficiency / Синтетический признак Study Efficiency

代码：

``` python
data["Study Efficiency"] = (
    data["Hours Studied"] * data["Previous Scores"] / 100
)
```

公式：

\[ StudyEfficiency= `\frac{HoursStudied\cdot PreviousScores}{100}`{=tex}
\]

这是一个**特征工程（feature engineering）**操作，也是交互特征的一种。

**中文**

普通线性模型分别考虑 `Hours Studied` 和 `Previous Scores`：

\[ `\theta`{=tex}\_1H+`\theta`{=tex}\_2P \]

加入乘积后还可以表示：

\[ `\theta`{=tex}\_3HP \]

也就是说，"学习时间的作用是否会随过去成绩变化"可以通过这个交互项部分表达。

不过报告结果中，该特征的标准化系数只有约
0.0179，说明在已经包含原始两个特征后，它提供的额外线性信息很小。

**Русский**

Это пример feature engineering и взаимодействия признаков. Произведение
(H`\cdot `{=tex}P) позволяет модели учитывать совместное влияние времени
учёбы и предыдущих результатов. Однако после включения исходных
признаков дополнительный линейный вклад этого признака оказался
небольшим.

------------------------------------------------------------------------

## 16. 为什么模型 2 比模型 1 强很多？ / Почему модель 2 намного лучше модели 1?

模型 1：

\[ R\^2=0.1468 \]

模型 2：

\[ R\^2=0.8377 \]

报告中的关键依据是 `Previous Scores` 与目标的相关系数约为 0.915，而模型
1 的几个学习习惯变量与目标关系明显较弱。

因此，模型 2 虽然特征数量更少，但包含了信息量很高的 `Previous Scores`。

**Русский**

Количество признаков само по себе не определяет качество. Во второй
модели присутствует `Previous Scores`, который имеет очень сильную
линейную связь с `Performance Index`. Поэтому два информативных признака
могут дать результат лучше, чем большее число слабых признаков.

------------------------------------------------------------------------

## 17. 为什么模型 3 最好？ / Почему модель 3 показывает лучший результат?

模型 3 同时使用：

\[
Hours, PreviousScores, Extracurricular, Sleep, Papers, StudyEfficiency
\]

测试结果：

\[ R\^2=0.9886,`\quad `{=tex}RMSE=2.0648,`\quad `{=tex}MAE=1.6398 \]

报告中模型 3 最大的标准化系数为：

-   `Previous Scores`: 17.6080
-   `Hours Studied`: 7.3571

其他特征明显较小。

**中文**

这说明在这个数据集和这次划分中，过去成绩和学习时间提供了最主要的预测信息。注意：系数大小表示模型中的线性关联贡献，不应直接解释成因果关系。

**Русский**

В данном наборе данных основной вклад в линейный прогноз дают
`Previous Scores` и `Hours Studied`. Но коэффициенты модели
характеризуют статистическую связь внутри модели, а не доказывают
причинно-следственную зависимость.

## 18. 描述性统计量 / Описательная статистика

报告计算：

-   Mean / среднее
-   Standard deviation / стандартное отклонение
-   Minimum / минимум
-   Q1
-   Median / медиана
-   Q3
-   Maximum / максимум

### 均值 / Среднее

\[ `\bar `{=tex}x=`\frac`{=tex}1n`\sum`{=tex}\_{i=1}\^{n}x_i \]

## 19. 预测函数为什么再次加全 1 列？ / Почему `predict` снова добавляет единицы?

``` python
return np.column_stack([np.ones(len(x)), x]) @ theta
```

训练时的参数包括：

\[
`\theta`{=tex}=\[`\theta`{=tex}\_0,`\theta`{=tex}\_1,`\dots`{=tex},`\theta`{=tex}\_p\]
\]

因此预测时输入矩阵也必须具有与训练时完全相同的结构：

\[ \[1,x_1,`\dots`{=tex},x_p\] \]

否则矩阵维度不匹配，而且无法使用已经学到的截距。

## 20. `std[std == 0] = 1` 是什么？ / Зачем `std[std == 0] = 1`?

若某一列所有值完全相同：

\[ `\sigma=0`{=tex} \]

标准化：

\[ `\frac{x-\mu}{0}`{=tex} \]

会发生除零错误。

因此代码将 0 标准差替换成 1。因为常数列满足
(x-`\mu=0`{=tex})，最终标准化值仍然全部为 0。

**Русский**

Это защита от деления на ноль. Для постоянного признака числитель
(x-`\mu`{=tex}) всё равно равен нулю, поэтому замена нулевого
стандартного отклонения на 1 безопасно даёт нулевой стандартизованный
признак.

## 24. 最容易混淆的几个概念 / Что чаще всего путают

### 24.1 回归 ≠ 分类 / Регрессия ≠ классификация

本实验预测的是连续数值 `Performance Index`，因此是回归。

### 24.2 相关 ≠ 回归 / Корреляция ≠ регрессия

相关系数描述两个变量的线性关联强弱；回归建立从多个输入到目标值的预测模型。

### 24.3 MSE ≠ RMSE

训练目标是 MSE：

\[ MSE=`\frac`{=tex}1n`\sum `{=tex}e_i\^2 \]

报告展示 RMSE：

\[ RMSE=`\sqrt{MSE}`{=tex} \]

RMSE 与目标变量单位相同，更容易解释。

### 24.4 标准化 ≠ 归一化到 \[0,1\]

本代码使用 Z-score：

\[ z=(x-`\mu`{=tex})/`\sigma`{=tex} \]

不是：

\[ (x-x\_{min})/(x\_{max}-x\_{min}) \]

### 24.5 高 R² ≠ 因果关系

高 R²
只说明模型在当前数据和测试划分上有很强的预测/拟合能力，不证明某个特征"导致"成绩变化。

# 26. 答辩必会问题 / Основные вопросы к защите

### Q1. 什么是线性回归？ / Что такое линейная регрессия?

**中文：**
线性回归用输入特征的线性组合预测连续目标变量，参数通过最小化预测值与真实值之间的平方误差得到。

**Русский:** Линейная регрессия предсказывает непрерывную целевую
переменную как линейную комбинацию признаков. Коэффициенты выбираются
так, чтобы минимизировать квадратичную ошибку.

### Q2. 为什么使用梯度下降？ / Зачем нужен градиентный спуск?

**中文：**
为了迭代寻找使损失函数最小的参数。本实验要求不使用现成回归模型，所以手动实现梯度下降。

**Русский:** Градиентный спуск итеративно изменяет коэффициенты в
направлении уменьшения функции потерь и позволяет самостоятельно обучить
модель без готовой функции регрессии.

### Q3. 为什么公式前有 (2/n)？ / Откуда берётся (2/n)?

因为对

\[ `\frac`{=tex}1n(X`\theta`{=tex}-y)\^T(X`\theta`{=tex}-y) \]

关于 (`\theta`{=tex}) 求导后得到：

\[ `\frac`{=tex}2nX\^T(X`\theta`{=tex}-y) \]

### Q4. 学习率太大会怎样？ / Что будет при слишком большом learning rate?

**中文：** 可能跨过最小值、震荡甚至发散。太小则收敛很慢。

**Русский:** При слишком большом шаге алгоритм может перескакивать
минимум и расходиться; при слишком маленьком --- сходиться слишком
медленно.

### Q5. 为什么测试集不能参与标准化参数计算？

**中文：** 会产生数据泄漏，使测试结果过于乐观。

**Русский:** Это привело бы к утечке информации из тестовой выборки и
сделало бы оценку качества менее независимой.

### Q6. R²=0.9886 是什么意思？

**中文：** 在该测试集上，模型相对于均值基准解释了约 98.86%
的目标变量变异。

**Русский:** На данной тестовой выборке модель объясняет около 98.86%
вариации целевой переменной относительно базового прогноза средним.

### Q7. 为什么还要 RMSE 和 MAE？

**中文：** R² 是相对指标，而 RMSE 和 MAE 直接用 Performance Index
的单位表示误差，更直观；RMSE 对大误差更敏感。

**Русский:** R² --- относительная характеристика, а RMSE и MAE
показывают размер ошибки в единицах целевой переменной. RMSE сильнее
реагирует на крупные ошибки.

### Q8. 什么是合成特征？

**中文：** 由已有特征通过数学变换构造的新特征。本实验的
`Study Efficiency = Hours Studied × Previous Scores / 100`
是一个交互特征。

**Русский:** Синтетический признак создаётся из исходных признаков.
Здесь `Study Efficiency` --- произведение времени учёбы и предыдущих
баллов, делённое на 100.

### Q9. 为什么模型 2 的特征更少却比模型 1 好？

**中文：** 因为特征数量不是关键，信息量才是关键。`Previous Scores`
与目标变量的线性相关约为 0.915，因此非常有预测价值。

**Русский:** Важнее информативность признаков, а не их количество.
`Previous Scores` имеет сильную линейную связь с целевой переменной.

### Q10. 这个实验是最小二乘还是梯度下降？

**中文：**
两者并不矛盾。**最小二乘**定义了优化目标------最小化平方误差；**梯度下降**是寻找这个最小值的数值优化方法。

**Русский:** Противоречия нет. **Метод наименьших квадратов** задаёт
цель --- минимизировать сумму квадратов ошибок, а **градиентный спуск**
является способом численно найти минимум.

# 27. 一分钟理解整个程序 / Вся программа за одну минуту

**中文**

程序首先读取学生成绩数据并删除重复项；构造 `Study Efficiency`；随机按
80/20
划分训练集和测试集；针对每个模型处理缺失值、类别编码，并只根据训练集进行标准化。随后给特征矩阵增加全
1 列作为截距，通过

\[ `\nabla `{=tex}J=`\frac`{=tex}2nX\^T(X`\theta`{=tex}-y) \]

计算梯度，并用

\[
`\theta`{=tex}`\leftarrow`{=tex}`\theta`{=tex}-`\alpha`{=tex}`\nabla `{=tex}J
\]

不断更新参数，直到收敛。最后在测试集上预测，并计算
R²、RMSE、MAE。实验中第三个模型表现最好，其中 `Previous Scores` 和
`Hours Studied` 是主要预测特征。

**Русский**

Программа загружает данные, удаляет дубликаты, создаёт
`Study Efficiency` и делит данные на 80% обучения и 20% теста. Для
каждой модели обрабатываются пропуски, кодируются категории и
выполняется стандартизация только по обучающей выборке. Затем
добавляется столбец единиц для свободного члена. Градиент вычисляется
как

\[ `\nabla `{=tex}J=`\frac`{=tex}2nX\^T(X`\theta`{=tex}-y), \]

а коэффициенты обновляются по правилу

\[
`\theta`{=tex}`\leftarrow`{=tex}`\theta`{=tex}-`\alpha`{=tex}`\nabla `{=tex}J.
\]

После сходимости модель проверяется на тестовой выборке с помощью R²,
RMSE и MAE. Лучший результат показывает третья модель; наиболее
информативными признаками являются `Previous Scores` и `Hours Studied`.

\[ `\boxed{\hat y=\theta_0+\sum_{j=1}^{p}\theta_jx_j}`{=tex} \]

\[ `\boxed{J(\theta)=\frac1n\sum_{i=1}^{n}(\hat y_i-y_i)^2}`{=tex} \]

\[ `\boxed{\nabla J(\theta)=\frac2nX^T(X\theta-y)}`{=tex} \]

\[ `\boxed{\theta\leftarrow\theta-\alpha\nabla J(\theta)}`{=tex} \]

\[ `\boxed{z=\frac{x-\mu}{\sigma}}`{=tex} \]

\[ `\boxed{R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}}`{=tex}
\]

\[ `\boxed{RMSE=\sqrt{\frac1n\sum(y_i-\hat y_i)^2}}`{=tex} \]

\[ `\boxed{MAE=\frac1n\sum|y_i-\hat y_i|}`{=tex} \]

\[
`\boxed{StudyEfficiency=\frac{HoursStudied\cdot PreviousScores}{100}}`{=tex}
