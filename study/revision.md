## 第 1 学期：基础概念与第一次实验

- **数学与线性代数**：[分析基础](../Math/Analysis.md)、[函数与极限](../Math/AdvancedMathematic.md)、[矩阵与线性空间](../Math/LinearAlgebra/1.md)、[集合与离散基础](../Math/DisMathematic.md)。闭卷解释一个定义，再完成原笔记中的例子。
- **信息学**：[信息与编码](../Informatics/Lecture/Lecture1.md)、[编码与数制](../Informatics/Lecture/Lecture2.md)、[Python 与正则](../Informatics/Lecture/Lecture3.md)。把术语与实际转换 / 处理步骤对应。
- **编程与 OPD**：[编程 Lab1](../Programming/lab1.md)、[Lab2](../Programming/lab2.md)、[OPD 指令基础](../OPD/Part1.md)、[Linux 双语问答](../OPD/lab/lab1/quesOfLab1.md)。以作业要求检查实际代码，不把要求文本当作完成证明。
- **历史与俄语**：[历史考试题单](../History/exam/ans.md)、[俄语词汇](../RussianLanguage/words.md)。历史文件提供题目清单；应结合已有报告准备口述，不能当作完整标准答案。

## 第 2 学期：关系数据库、OOP 与数学延续

- **数据库**：[考试任务](../Database/Exam.md) → [Lab3 规范化问答](../Database/labs/lab3/questions.md) → [Lab4 执行计划](../Database/labs/lab4/questions.md)。练一组 ER 模型、约束、连接查询和执行计划解释；考试文件是任务材料。
- **编程**：[OOP Lab3–4](../Programming/lab3-4.md) → [集合 Lab5](../Programming/lab5.md) → [网络 Lab6](../Programming/lab6.md) → [并发/JDBC Lab7](../Programming/lab7.md) → [第二学期阶段题](../Programming/rub/SecSem.md)。用自己的项目解释类关系、集合选择与并发边界。
- **线性代数、离散数学、OPD**：[第二学期线代测试](../Math/LinearAlgebra/Sem2/final_test.md)、[离散数学目录](../DiscreteMath/index.md)、[I/O 与中断](../OPD/Part3.md)、[OPD 考试题](../OPD/exam/Билеты_экзамен.docx)。俄语和历史继续使用前一学期的共享材料。

## 第 3 学期：Web、概率与多元分析

- **Web 理论路线**：[HTTP/HTML/CSS/JS](../WebProgramming/Ans/answer1.md) → [Servlet/JSP/MVC](../WebProgramming/Ans/answer2.md) → [JSF/JPA](../WebProgramming/Ans/answer3.md) → [Java EE/Spring](../WebProgramming/Ans/answer4.md)。再从[阶段理论题](../WebProgramming/Exam/rub2.md)和[代码题](../WebProgramming/Exam/code_rub2.md)各选一题，先独立回答再对照。
- **数学路线**：[补充数学分析](../Math/ExtraMath/ans.md)、[概率论课件](../ProbabilityTheory/index.md)、[复变函数资料](../ComplexVariableTheory(ТФКП)/index.md)。概率论和复变材料主要按 PDF / 实验阅读，不假定已有完整 Markdown 答案。
- **编程语言与物理**：[编程语言目录](../ProgrammingLanguage/index.md)、[异步练习说明](../ProgrammingLanguage/work5/readme.md)、[物理实验目录](../Physics/index.md)。以当前代码与实验报告解释流程，俄语继续读[词汇表](../RussianLanguage/words.md)。

## 第 4 学期：体系、算法与数值方法

- **计算机体系结构**：[速查](../ComputerArchitecture/quick-review.md) → [口述答案](../ComputerArchitecture/Exam/CSA_2026_Экзаменационные_ответы_устно.md) → [完整解释](../ComputerArchitecture/Exam/CSA_2026_Экзаменационные_ответы.md)。完整文件有未随仓库提供的图引用，读到图题时结合文字与现有 Lab3 图示核对。
- **软件工程 OPI**：[2025–2026 中俄试卷讲解](../OPI/Exam/ОПИ_2025-2026.md)、[阶段理论](../OPI/Rub/theory.md)、[JMX 问答](../OPI/Lab4/ans.md)。用 Lab2 的版本控制、Lab3 的构建资料和 Lab4 的监控代码支撑答案。
- **算法与计算数学**：[AADS 内容](../AADS/content.md)、[数值方法速查](../ComputationalMath/cheatsheet.md)。AADS 的短笔记以已有 C++ 实现配合阅读；计算数学按函数入口追踪输入、算法、精度与输出。
- **统计与其他课程**：[数学统计目录](../MathematicalStatistics/index.md)、[优化方法目录](../OptiMethod/index.md)、[物理实验目录](../Physics/index.md)、[公众演讲](../PublicPresentation/index.md)。部分材料是代码、PDF 或报告，需要打开对应资源。

## 复习后的闭卷检查

选一个概念，用 **中文解释 → 俄语 30 秒 → 原笔记核对 → 实际代码举例** 的顺序练习。答错时回到来源修改自己的理解；复习耗时和“读过”都不代表掌握，更不代表课程通过。
