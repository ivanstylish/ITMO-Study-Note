# 维护规则 · Правила ведения

[首页](../README.md) · [课程总览](courses.md) · [VS Code / GitHub 阅读](reading.md)

## 保持单一资料来源

课程原目录继续存放笔记、代码、报告和图像。新建 `index.md` 是课程导航；同一课程跨学期共享入口。导航结构由 [catalog.json](catalog.json) 管理，不从文件夹名猜学期、不从复选框猜完成度。

新增真实资料后，在对应课程的 `resources` 中填写 `{ "label": "…", "path": "仓库相对路径" }`。可用类型为 `theory`、`labs`、`defense`、`exam`、`resources`。必须先有文件再增加入口；不要求每门课具备全部类型。`related` 填已有课程 id，生成双向关联时分别在两门课程配置。

```sh
node tools/generate-index.mjs
node tools/update-course-links.mjs
```

生成器更新课程 Dashboard、学期页、课程/实验总览；不要直接编辑带有 `Generated by` 标记的页面。导航检查只要求维护范围内的链接有效，历史笔记未修复的链接另列清单，不把旧断链伪装为修复成功。

阅读 Markdown 和更新导航无需网站依赖。若要运行完整链接检查，可安装项目依赖后执行 `npm run kb:check`；[网站构建](website.md)按需使用。

## 元数据与状态

新笔记可逐渐使用下列可选 Frontmatter；旧笔记不批量补标签：

```yaml
---
course: os
semester: 5
type: defense
topic: [memory, file-io, measurement]
status: review
---
```

- `course`：catalog 的课程 id；`semester`：实际学期，跨学期文件可省略。
- `type`：`theory` / `lab` / `exam` / `defense` / `cheatsheet` / `resource`。
- `topic`：少量可搜索的关键词，正文保留中文和俄语术语。
- `status`：`learning` / `review` / `completed`，只表示本人确认的学习状态。教师验收或考试结果应有单独记录，不能由文件存在推断。

## 路径与实验版本

新增专题推荐英文小写加连字符，例如 `quick-review.md`。旧文件名、大小写、实验编号及提交包保持原样；GitHub 链接使用标准 Markdown 相对路径，含空格的路径使用 URL 编码。

本地补回的不同实现放在 `local-source` 或 `local-variant`，避免覆盖已经收录的版本。每个快照有说明和 SHA256 清单；配置、密钥、IDE 缓存及构建产物不随源码归档。仓库此前已跟踪的依赖不会因为新增 `.gitignore` 自动从历史删除；本次不清理原始文件。

归档后的快照默认保持不变；若主动修改其中源码，要在审阅变更后同时更新 `import-manifest.json` 中对应文件的 SHA256 和字节数，保证持续校验有意义。导入工具会拒绝用本地版本覆盖内容不同的文件。导航生成器只写带有生成标记的页面，错误的路径或与原笔记重名的目标会被拒绝。

大 PDF / DOCX / PPT 和实验代码不复制进网站；网站投影可重新生成，不单独编辑。阅读站点不会执行实验程序，也不等于实验重新构建或验收通过。
