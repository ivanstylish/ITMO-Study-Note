# 实验二答辩学习笔记：点光源照射下的球面亮度

本文分为中文笔记和完整俄语译文两部分；公式、代码说明和实验结果保持一致。

本文按实验题目、报告和 `lab2_sphere.py` 整理。建议答辩时先说明坐标系与模型约定，再从屏幕射线讲到球面着色，最后用解析值和导出图像说明程序经过验证。

## 一分钟概述

程序从观察者穿过矩形屏幕像素中心发出透视射线，与球面求交以确定可见的表面点。对每个点计算外法向、观察方向和到各光源的方向，分别用朗伯余弦定律求光源强度与表面入射量，再使用 Blinn–Phong 半程向量模型计算漫反射和镜面反射。把所有光源贡献相加得到绝对亮度，在球面可见像素内以最大值归一化为 8 位灰度，并保存图像、色彩图、截面和数值结果。

## 题目要点与实验约定

- 输入包括矩形屏幕大小与分辨率、点光源坐标与轴向辐射强度、观察者位置和观察方向、球心和半径、表面系数。
- 屏幕宽高和分辨率应形成正方形像素：`W/Wres = H/Hres`。程序由 `Hres=round(Wres·H/W)` 自动计算纵向分辨率；本实验默认使用 `1200×1200 mm`、`600×600 px`，每个像素边长为 `2 mm`。非整数比例时按最近整数像素取整。
- 推荐的球心 `xC,yC` 与光源 `xL,yL` 范围是 `−10000…10000 mm`，球心 `zC` 与光源 `zL` 是 `100…10000 mm`，光源 `I0` 是 `0.01…10000 W/sr`。程序还会检查平方像素、观察者和光源在球外，以及球体完整落入视锥。
- 默认观察者 `O=(0,0,2500) mm`，朝向 `−Z`；屏幕中心直接设为 `z_s=0`。一般情况下用户输入屏幕中心的 `z_s` 坐标，屏幕位于观察者视线与该 z 坐标相交的位置；程序检查球在观察者前方、在屏幕之前且完整落入视锥。对于沿 z 轴观察的情况，球在观察者与屏幕之间的条件为 `zO > zC+R > zC−R > z_s`（从上向下观察）或 `zO < zC−R < zC+R < z_s`（从下向上观察）。观察者可从 `+Z` 或 `−Z` 一侧观察。每盏朗伯点光源有独立发射轴，默认方向为 `−Z`。球心 `C=(0,0,600) mm`，半径 `R=350 mm`。
- 两盏光源分别位于 `L1=(−650,450,1700) mm`、`I01=100 W/sr` 和 `L2=(550,−250,1600) mm`、`I02=70 W/sr`。
- `kd=0.20 sr⁻¹`、`ks=0.80 sr⁻¹`、光泽指数 `m=80`，产生两个明显的镜面高光。

## 必须掌握的公式

### 相机、像素与透视射线

相机基向量为前向 `d`、屏幕向右 `er`、屏幕向上 `eu`。用叉积构造正交方向。对从左上角开始编号的像素 `(i,j)`，其物理中心为

```text
xj = -W/2 + (j + 1/2) W/Wres
y_i =  H/2 - (i + 1/2) H/Hres
q_ij = normalize(s d + xj er + y_i eu)
P(t) = O + t q_ij
```

这里用户直接设置屏幕中心的 `z_s` 坐标。代码依据观察方向求出屏幕中心 `S`（满足 `S=O+s d` 且 `S_z=z_s`），再用向量 `S−O` 生成像素射线；`s` 只是投影内部的计算量，不是界面输入参数。`q` 是单位射线方向，所以 `t` 使用与 `O、C、R` 相同的长度单位。行号从上往下增加，因此 y 坐标从高到低变化。代码的 `calculate()` 建立像素中心坐标，`camera_basis()` 建立相机坐标系，`trace()` 生成单位射线。

`zO` 与 `z_s` 分别设置观察者和屏幕中心在 z 轴上的位置。屏幕位置直接通过 `z_s` 控制；改变 `z_s` 会改变屏幕相对观察者和球体的位置，从而改变视野角。沿 `−Z` 观察时屏幕的 z 坐标应小于球体最低点；沿 `+Z` 观察时屏幕的 z 坐标应大于球体最高点。

从球体下方观察的示例为 `O=(0,0,0) mm`、`d=(0,0,1)`、屏幕中心 `z_s=1200 mm`，配置文件是 `parameters_from_below.json`。屏幕平面位于球体之后，球体完整处于观察者与屏幕之间；观察者在球最低点 `z=250 mm` 以下并朝 `+Z` 观察。注意默认两个光源都在上方且沿 `−Z` 发光，所以下表面可能很暗；这是光照条件造成的，不是相机算法错误。

### 射线与球相交

球面满足 `|P−C|²=R²`。将射线方程代入球面方程，定义

```text
oc = O - C
b  = q · oc
c  = oc · oc - R²
D  = b² - c
t  = -b - sqrt(D)       # 最近交点
P  = O + t q
n  = normalize(P - C)   # 球面外法向
```

当 `D<0` 时射线没有穿过球，像素保持背景色。观察者位于球外时，选择较小的正根 `t` 可得到球面前侧的最近交点；背侧交点被遮挡。代码中的 `trace()` 批量计算判别式、命中掩码和交点，`calculate()` 只对命中像素计算亮度。

视锥检查保证整个球都在图像里：代码检查球心到四个屏幕侧面的有符号距离都不小于 `R`，并检查球体最前端仍在观察者前方。只检查投影中心不够，因为球边缘仍可能被裁切。

### 朗伯点光源与余弦项

对第 `i` 个光源，定义从表面点指向光源的单位向量 `li`，从表面点指向观察者的单位向量 `v`，光源的单位发射轴为 `a_i`。从光源指向表面点的方向是 `−li`，故朗伯发射余弦为 `max(a_i·(−li),0)`。默认 `a_i=(0,0,−1)` 时，它等于 `max(li,z,0)`；界面允许为每盏灯单独改变 `a_i`。

```text
ri = |Li - P| / 1000                 # mm 换算成 m
li = normalize(Li - P)
I_i(θ) = I0_i max(a_i·(-li), 0)            # W/sr
Ei(P) = I0_i max(a_i·(-li),0) max(n·li,0) / ri²  # W/m²
```

两个余弦有不同作用：`max(a_i·(−li),0)` 是由发射轴决定的光源方向图；`max(n·li,0)` 是接收表面的投影余弦。负值截为零，表示光源不朝背面发光、表面背光侧不接收该光源的直接照明。`ri` 必须用米，因为辐射强度单位是 `W/sr`，而要求能量照度 `W/m²`。

在代码里，`radiance_at()` 先算 `to_light`，将它除以 `1000` 后求距离平方，再将每盏灯输入的 `axis` 归一化为 `a_i`，用 `a_i·(−l)` 算发射余弦。每盏灯单独产生一个照度贡献，随后累加。默认参数采用题目图示的 `−Z` 光轴方向。

### Blinn–Phong 反射和绝对亮度

半程向量是光线方向与观察方向的夹角平分方向：

```text
h_i = normalize(li + v)
f_i = kd + ks max(n · h_i, 0)^m
L(P,v) = Σ_i Ei(P) f_i
       = Ldiffuse + Lspecular
Ldiffuse = Σ_i Ei(P) kd
Lspecular = Σ_i Ei(P) ks max(n · h_i, 0)^m
```

其中 `L_i(P,v)=E_i(P) f_i` 表示第 `i` 盏灯在表面点 `P`、朝观察方向 `v` 产生的亮度贡献：`E_i(P)` 是该灯在表面上的照度，`f_i` 是题目给定的反射函数（此处为 Blinn–Phong 经验项）。总亮度 `L` 是所有灯贡献的和。

`n·h` 越接近 `1`，镜面高光越强。增大 `m` 会让高光更窄、更集中；减小 `m` 会让高光更宽。漫反射随表面法向和光线的夹角变化；镜面反射还取决于观察方向，所以观察者移动时高光位置也会变化。

本程序按题目示意图使用经验反射函数 `kd + ks(n·h)^m`，没有另加不同文献中的镜面归一化因子。`kd` 和 `ks` 按 `sr⁻¹` 处理，故 `L` 的单位是 `W/(m²·sr)`。这是模型下的能量亮度，不是像素灰度，也不是 `cd/m²` 的光度亮度。没有光源光谱时不能把它换算成坎德拉亮度。

代码 `radiance_at()` 另外检查 `n·v>0`：表面朝向观察者的正半球才产生朝观察者发出的亮度。对每个光源，函数把漫反射与镜面项分别累计，便于生成截面图和控制点表。

### 灰度归一化

只在球体命中的像素中找最大值 `Lmax`，再计算

```text
Gij = round(255 Lij / Lmax),  sphere pixels
Gij = 0,                         background pixels
```

结果存为 `uint8`，即 `[0,255]` 的单通道 PNG。它表示同一次渲染内部的相对亮度：最高亮度对应 `255`，不是物理单位。绝对亮度保存在 `radiance_data.npz` 与 `results.json`。若最大值为零，程序保留全黑图像并避免除以零。实现见 `calculate()` 和 `save_results()`。

## 本实验结果，答辩时要记住

三个控制点由球面法向 `n1=(0,0,1)`、`n2=(−0.6,0,0.8)`、`n3=(0.6,0,0.8)` 定义，位置是 `P=C+Rn`。它们都朝向观察者。代码直接在这些坐标计算亮度，不从栅格图像取最近像素。

| 点 | 坐标 mm | 漫反射 `W/(m²·sr)` | 镜面反射 `W/(m²·sr)` | 总亮度 `W/(m²·sr)` |
|---|---:|---:|---:|---:|
| P1 | `(0, 0, 950)` | 17.515758 | 0.158479 | **17.674237** |
| P2 | `(−210, 0, 880)` | 14.116729 | 0.000403 | **14.117132** |
| P3 | `(210, 0, 880)` | 17.088220 | 0.000882 | **17.089102** |

可见球面共命中 `172448` 个像素中心。可见图像的最低亮度是 `0 W/(m²·sr)`，最高亮度是 `79.375576 W/(m²·sr)`，平均值是 `14.944841 W/(m²·sr)`。背景不参与这些统计，但未照亮的可见表面仍参与，故最小值可以是零。

程序还对整个球面进行角度采样：`361` 个极角乘 `720` 个方位角，所得离散最大值是 `79.325340 W/(m²·sr)`。它与图像像素网格不是同一组点；有限采样也不能保证找到连续表面的精确峰值。因此答辩时要说清楚，报告主结果的极值来自可见图像网格；全球面角度网格的值是额外的离散估算。

## 验证思路

本项目的 `test_lab2.py` 含十三项自动检查，覆盖公式、几何、光源方向、分辨率比例、屏幕 z 坐标和文件导出：

1. **轴向解析值。** 只保留轴上光源 `L=(0,0,1700) mm`，取点 `P=(0,0,950) mm`。此时 `r=0.75 m`，`li,z=n·li=n·h=1`。设置 `I0=100 W/sr` 且 `kd+ks=1 sr⁻¹`，应得 `L=100/0.75²=177.777778 W/(m²·sr)`。
2. **几何关系。** 中央像素射线应打到球体前端附近；每个交点都满足 `|P−C|≈R`。屏幕角落射线应与球相离。
3. **线性与可加性。** 所有光源强度乘 `2`，绝对亮度也乘 `2`；各灯分别计算后求和，应等于多灯联合计算。每幅图都按自己的最大值归一化时，灰度图保持相同。
4. **边界情况。** `kd=ks=0` 产生全黑图像但不除零；背景像素固定为零；球背面朝观察者的亮度为零。
5. **输入与文件。** `Hres` 会随物理屏幕比例自动计算；零观察方向、被视锥裁切的球、屏幕位于球体之前、以及位于球内的光源会被拒绝。翻转光源轴会改变其照明方向。重新读出的 PNG 应具有指定大小，并与计算得到的灰度数组一致。


生成默认图像和结果：

```bash

```

启动窗口：


窗口可编辑场景参数及任意数量光源。屏幕位置直接输入 `z экрана`；编辑屏幕宽高和横向像素数 `Wres` 后，纵向像素数 `Hres` 会按比例自动更新。点击“Пример: вид снизу (+Z)”会填入观察者在 `z=0`、观察方向 `+Z`、屏幕 `z=1200 mm`、物理尺寸 `2000×2000 mm` 的可运行示例。每个光源单独一行，格式是 `x y z I0 ax ay az`；后三个数是该灯的发射轴方向。点击“Рассчитать”重新计算，“Сохранить результаты”选择输出文件夹。

## 常见答辩问题

**问：为什么有两个余弦？**  答：`max(a_i·(−li),0)` 计算朗伯光源朝表面方向的发射强度；`max(n·li,0)` 计算表面法向的投影和接收量。一个是光源方向图，一个是接收面的余弦定律。

**问：为什么距离必须从毫米换成米？**  答：`I0` 的单位是 `W/sr`。平方反比公式只有用 `m²` 才能得到 `W/m²` 的照度；向反射函数乘以 `sr⁻¹` 后才得到 `W/(m²·sr)` 的亮度。

**问：Blinn–Phong 与 Phong 的区别是什么？**  答：Phong 用理想反射方向与观察方向的夹角；Blinn–Phong 用光线方向和观察方向之间的半程向量 `h`，高光项是 `max(n·h,0)^m`。本程序实现后者。

**问：改变 `m` 会怎样？**  答：`m` 越大，高光越窄，峰值越集中；`m` 越小，高光越宽。它主要控制镜面高光的形状。

**问：为什么高光不恰好落在光源的投影上？**  答：镜面项取决于 `n` 是否对齐 `h=normalize(l+v)`，由光源方向与观察方向共同决定，而不是只由入射光方向决定。

**问：亮度最小值为什么是零？**  答：球面有未被任何光源照亮的区域；这些点是球面命中像素，故参与最小值。屏幕背景是另一类像素，不参与球面统计。

**问：为什么灰度最大值总是 255？这代表什么？**  答：每次把图像内亮度除以同一幅图的最大值再乘 255，所以图中峰值映射到 255。它代表相对灰度，不表示 `255 W/(m²·sr)`。

**问：为什么用射线求交，而不是给球面画一个圆？**  答：圆只给出轮廓，无法确定球面每个可见像素在三维空间的位置和法向量。射线求交给出表面点，才能正确计算受光方向、观察方向与高光。

**问：程序如何保证球完整出现在屏幕内？**  答：检查球心到视锥四个侧面的距离都不小于半径，同时确认球在观察者前方。只检查球心投影会漏掉被裁掉的轮廓。

**问：全表面估算的最大值为什么和图像最大值不同？**  答：图像只采样屏幕像素中心且只包括可见面；角度网格在球面上均匀取样。二者位置和采样密度都不同，离散最大值自然可能不同。

**问：这个结果是物理照片吗？**  答：不是。它是按题目给定的朗伯发光方向图、余弦受光和经验 Blinn–Phong 反射模型计算的能量亮度分布，没有光谱、纹理、环境光或照片测量。

## 复习口诀

```text
像素中心定射线 → 最近正根得表面点 → P−C 得法线
L−P 得光方向，O−P 得观察方向
朗伯光源余弦 × 表面入射余弦 → 照度 E
l 与 v 的半程向量 h → 漫反射 + 镜面反射
可见球面最大值归一化 → 8 位灰度图
```

## Краткое объяснение за одну минуту

Программа выпускает перспективные лучи из наблюдателя через центры пикселей прямоугольного экрана. Пересечение луча со сферой определяет видимую точку поверхности. Для каждой точки вычисляются внешняя нормаль, направление на наблюдателя и направления на источники света. Закон косинусов Ламберта задаёт диаграмму излучения источников и количество света, принимаемое поверхностью; модель Блинна–Фонга рассчитывает диффузное и зеркальное отражение. Вклады всех источников суммируются. Абсолютная яркость нормируется на максимум среди видимых точек сферы и записывается в виде восьмибитного изображения. Программа также сохраняет цветовую карту, сечение и численные результаты.

## Постановка задачи и принятые соглашения

- Параметры задачи: размеры и разрешение прямоугольного экрана, координаты точечных источников и осевая сила излучения, положение и направление наблюдения, центр и радиус сферы, коэффициенты отражения поверхности.
- Ширина и высота одного пикселя должны совпадать: `W/Wres = H/Hres`. Программа автоматически рассчитывает `Hres=round(Wres·H/W)`; в стандартном варианте размеры экрана составляют `1200×1200 мм`, разрешение — `600×600 пикселей`, размер пикселя — `2 мм`. При нецелом отношении используется ближайшее целое число пикселей.
- Рекомендуемые диапазоны: `xC,yC,xL,yL = −10000…10000 мм`; `zC,zL = 100…10000 мм`; `I0 = 0,01…10000 Вт/ср`. Программа также проверяет квадратную форму пикселей, нахождение наблюдателя и источников вне сферы и полное размещение сферы внутри поля зрения.
- По умолчанию наблюдатель находится в `O=(0,0,2500) мм` и смотрит вдоль `−Z`; координата z центра экрана задаётся напрямую как `z_s=0`. Пользователь вводит `z_s`, а экран располагается на пересечении этого z-уровня с центральным лучом камеры. Программа проверяет, что сфера находится перед наблюдателем, экран расположен за сферой и вся сфера помещается в поле зрения. При наблюдении вдоль z-оси условие порядка объектов: `zO > zC+R > zC−R > z_s` при взгляде сверху или `zO < zC−R < zC+R < z_s` при взгляде снизу. У каждого ламбертовского источника своя настраиваемая ось излучения, по умолчанию направленная вдоль `−Z`. Центр сферы — `C=(0,0,600) мм`, радиус — `R=350 мм`.
- Источник `L1=(−650,450,1700) мм` имеет силу излучения `I01=100 Вт/ср`; источник `L2=(550,−250,1600) мм` — `I02=70 Вт/ср`.
- Параметры отражения: `kd=0,20 ср⁻¹`, `ks=0,80 ср⁻¹`, показатель блеска `m=80`. Этот набор параметров создаёт два заметных зеркальных блика.

## Основные формулы

### Камера, пиксели и перспективный луч

Обозначим через `d` направление камеры вперёд, через `er` — направление вправо в плоскости экрана, через `eu` — направление вверх. Направления строятся с помощью векторного произведения и образуют ортогональный базис. Для пикселя `(i,j)`, отсчёт которого начинается в верхнем левом углу, координаты центра равны:

```text
xj = -W/2 + (j + 1/2) W/Wres
y_i =  H/2 - (i + 1/2) H/Hres
q_ij = normalize(s d + xj er + y_i eu)
P(t) = O + t q_ij
```

Пользователь задаёт z-координату центра экрана `z_s`. Программа находит центр `S` экрана на центральном луче камеры с условием `S_z=z_s`; в формуле `s` — внутреннее расстояние вдоль луча, а не отдельный параметр ввода. Направление `q` нормировано, поэтому `t` выражен в тех же единицах длины, что и `O`, `C` и `R`. Номер строки увеличивается сверху вниз, поэтому координата `y` уменьшается. Функция `calculate()` задаёт координаты центров пикселей, `camera_basis()` формирует базис камеры, а `trace()` строит единичные лучи.

Параметр `zO` задаёт положение наблюдателя, а `z_s` — прямую z-координату центра экрана. Экран перемещается изменением `z_s`; при этом меняется угол обзора перспективной камеры. При наблюдении снизу экран задаётся выше сферы, а при наблюдении сверху — ниже сферы.

Пример наблюдения снизу: `O=(0,0,0) мм`, `d=(0,0,1)`, координата экрана `z_s=1200 мм`; он задан в файле `parameters_from_below.json`. Плоскость экрана находится на `z=1200 мм`, а сфера целиком между камерой и экраном. Камера ниже нижней точки сферы `z=250 мм` и смотрит вдоль `+Z`. Стандартные источники расположены сверху и излучают вдоль `−Z`, поэтому нижняя поверхность может быть тёмной из-за условий освещения, а не из-за ошибки камеры.

### Пересечение луча со сферой

Уравнение поверхности сферы: `|P−C|²=R²`. Подставляя в него уравнение луча, получаем:

```text
oc = O - C
b  = q · oc
c  = oc · oc - R²
D  = b² - c
t  = -b - sqrt(D)       # ближайшее пересечение
P  = O + t q
n  = normalize(P - C)   # внешняя нормаль сферы
```

Если `D<0`, луч проходит мимо сферы, и пиксель остаётся фоновым. Наблюдатель находится вне сферы; поэтому меньший положительный корень `t` соответствует ближайшей видимой точке передней поверхности, а дальняя точка закрыта сферой. Функция `trace()` векторно рассчитывает дискриминант, маску пересечений и координаты точек. В `calculate()` яркость вычисляется только для пикселей, попавших на сферу.

Полное попадание сферы в кадр проверяется по расстояниям от центра сферы до четырёх боковых плоскостей усечённой пирамиды видимости: каждое расстояние должно быть не меньше `R`. Дополнительно проверяется, что ближайшая часть сферы находится перед наблюдателем. Проверки одного только центра проекции недостаточно: края сферы могли бы выйти за пределы экрана.

### Ламбертовский точечный источник и косинусные множители

Для источника с индексом `i` вектор `li` направлен от точки поверхности к источнику, а `v` — от точки поверхности к наблюдателю. `a_i` — настраиваемая единичная ось излучения источника. Направление луча от источника к поверхности равно `−li`, поэтому косинус излучения равен `max(a_i·(−li),0)`. Для стандартного `a_i=(0,0,−1)` это выражение превращается в `max(li,z,0)`.

```text
ri = |Li - P| / 1000                 # перевод мм в м
li = normalize(Li - P)
I_i(θ) = I0_i max(a_i·(-li), 0)            # Вт/ср
Ei(P) = I0_i max(a_i·(-li),0) max(n·li,0) / ri²  # Вт/м²
```

Эти два косинуса описывают разные процессы. `max(a_i·(−li),0)` задаёт диаграмму направленного излучения источника; `max(n·li,0)` учитывает проекцию принимающей поверхности. Отрицательные значения ограничиваются нулём: источник не излучает в заднюю полусферу, а поверхность на теневой стороне не принимает прямой свет от этого источника. Величину `ri` необходимо выражать в метрах, поскольку сила излучения задана в `Вт/ср`, а энергетическая освещённость измеряется в `Вт/м²`.

В `radiance_at()` сначала вычисляется `to_light`; его длина переводится из миллиметров в метры для расчёта квадрата расстояния. Ось `axis` каждой лампы нормируется, затем скалярное произведение `a_i·(−l)` даёт косинус излучения. Вклад каждой лампы рассчитывается отдельно, после чего складывается с остальными. По умолчанию ось соответствует схеме задания и направлена вдоль `−Z`.

### Отражение по модели Блинна–Фонга и абсолютная яркость

Полувектор `h` делит пополам угол между направлением на источник и направлением на наблюдателя:

```text
h_i = normalize(li + v)
f_i = kd + ks max(n · h_i, 0)^m
L(P,v) = Σ_i Ei(P) f_i
       = Ldiffuse + Lspecular
Ldiffuse = Σ_i Ei(P) kd
Lspecular = Σ_i Ei(P) ks max(n · h_i, 0)^m
```

Здесь `L_i(P,v)=E_i(P) f_i` означает вклад яркости от `i`-го источника в точке `P` в направлении наблюдения `v`: `E_i(P)` — освещённость поверхности от этого источника, а `f_i` — заданная в работе функция отражения (эмпирический член Блинна–Фонга). Полная яркость `L` — сумма вкладов всех источников.

Чем ближе `n·h` к `1`, тем ярче зеркальный блик. При увеличении `m` блик становится уже и концентрированнее; при уменьшении `m` он становится шире. Диффузное отражение зависит от угла между нормалью и направлением света. Зеркальное отражение зависит также от направления на наблюдателя, поэтому положение блика меняется при перемещении камеры.

В программе применяется эмпирическая функция отражения из схемы задания: `kd + ks(n·h)^m`. Дополнительный нормирующий множитель для зеркального слагаемого не вводится. Коэффициентам `kd` и `ks` приписывается единица `ср⁻¹`, поэтому энергетическая яркость `L` измеряется в `Вт/(м²·ср)`. Эту величину нельзя путать с уровнем серого или фотометрической яркостью в `кд/м²`. Без спектрального распределения света перевод в канделы невозможен.

Функция `radiance_at()` дополнительно проверяет условие `n·v>0`: поверхность должна быть обращена к наблюдателю, чтобы излучать в его направлении. Диффузная и зеркальная составляющие накапливаются отдельно; это позволяет строить их графики в сечении и приводить отдельные значения в таблице контрольных точек.

### Нормировка в оттенки серого

Максимум `Lmax` вычисляется только среди пикселей, пересекающих сферу:

```text
Gij = round(255 Lij / Lmax),  пиксели сферы
Gij = 0,                         фон
```

Массив записывается как `uint8`, то есть одноканальный PNG со значениями `[0,255]`. Это относительная яркость внутри конкретного изображения: максимум соответствует `255`, что не означает `255 Вт/(м²·ср)`. Абсолютные значения сохраняются в `radiance_data.npz` и `results.json`. Если `Lmax=0`, изображение остаётся чёрным, а деления на ноль не происходит. Нормировка реализована в функциях `calculate()` и `save_results()`.

## Частые вопросы на защите

**Почему в формуле два косинуса?** `max(a_i·(−li),0)` описывает диаграмму излучения ламбертовского источника. `max(n·li,0)` учитывает проекцию поверхности и определяет, принимает ли она свет. Эти множители относятся к источнику и к принимающей поверхности соответственно.

**Почему расстояние переводится из миллиметров в метры?** Сила излучения измеряется в `Вт/ср`. В законе обратных квадратов расстояние должно быть выражено в метрах, чтобы получить освещённость `Вт/м²`. Умножение на функцию отражения с размерностью `ср⁻¹` даёт яркость `Вт/(м²·ср)`.

**Чем модель Блинна–Фонга отличается от модели Фонга?** В модели Фонга сравнивают направление наблюдения с идеальным отражённым направлением. В модели Блинна–Фонга используют полувектор `h`, направленный посередине между светом и наблюдателем; зеркальный член содержит `max(n·h,0)^m`. В программе реализована модель Блинна–Фонга.

**Что меняется при увеличении `m`?** Зеркальный блик становится уже и концентрированнее. При меньшем `m` блик расширяется. Показатель степени задаёт форму зеркального блика.

**Почему блик расположен не прямо под проекцией источника?** Зеркальная составляющая максимальна, когда нормаль совпадает с `h=normalize(l+v)`. Полувектор зависит одновременно от света и направления наблюдения.

**Почему минимальная яркость равна нулю?** На сфере есть точки, не освещённые ни одной лампой. Это точки поверхности, поэтому они участвуют в статистике видимых пикселей и могут дать нулевой минимум. Фоновые пиксели не участвуют.

**Почему максимум оттенка серого равен 255? Что означает это число?** Яркость каждого пикселя делится на максимум того же изображения, умножается на 255 и округляется. Поэтому самый яркий пиксель получает значение 255. Это относительный уровень серого, а не физическая яркость `255 Вт/(м²·ср)`.

**Почему нельзя просто нарисовать круг вместо пересечения лучей со сферой?** Круг задаёт лишь контур. Для расчёта освещения нужно найти положение каждой видимой точки в трёхмерном пространстве и её нормаль. Пересечение луча даёт эти данные, необходимые для расчёта света, наблюдения и бликов.

**Как программа гарантирует, что сфера целиком видна?** Она проверяет расстояния от центра до четырёх боковых плоскостей поля зрения и проверяет положение сферы относительно наблюдателя. Проверка только проекции центра не обнаружила бы обрезанные края.

**Почему максимум по всей сфере отличается от максимума изображения?** Изображение дискретно по центрам пикселей и содержит только видимую часть поверхности. Дополнительная сетка равномерно задаёт полярные и азимутальные углы на всей сфере. Положение и шаги узлов у этих сеток отличаются, поэтому их дискретные максимумы тоже могут различаться.

**Является ли результат фотографией или полноценной физической симуляцией?** Нет. Это распределение энергетической яркости, рассчитанное по диаграмме ламбертовских источников, косинусу приёма света и эмпирической модели отражения Блинна–Фонга. Спектр, текстуры, окружающий свет и измеренные фотографии в модели не используются.

## Краткая последовательность для повторения

```text
Центр пикселя задаёт луч → ближайший положительный корень задаёт точку поверхности → P−C задаёт нормаль
L−P задаёт направление на свет → O−P задаёт направление на наблюдателя
Косинус источника × косинус падения на поверхность → освещённость E
Полувектор между l и v → диффузное + зеркальное отражение
Нормировка по максимуму видимой сферы → восьмибитное изображение
```
