# Отчёт лабораторной работы 3 в Overleaf

1. Создайте проект в Overleaf через **New Project → Upload Project** и загрузите архив этого каталога.
2. Выберите основной файл `main.tex` и компилятор **XeLaTeX**.
3. Нажмите **Recompile**. При первом запуске повторная компиляция обновляет содержание и ссылки.

Отчёт написан непосредственно в LaTeX. Генератор на Python не нужен.

Проект использует две исходные схемы из задания в `figures/` и восемь изображений в `results/white/` и `results/colored/`. Эти PNG включены в архив, загрузка внешних файлов при компиляции не требуется. Полные абсолютные массивы NPZ относятся к программе и в Overleaf не загружаются.

Численные таблицы соответствуют стандартному опыту 600×600 пикселей. При изменении физической сцены сначала пересчитайте программу и обновите изображения и числа в `main.tex`.

Локальная сборка при установленном XeLaTeX:

```text
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```
