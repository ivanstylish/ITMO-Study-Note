https://www.figma.com/design/N7T7k0t15e4rOSuDu7UZeQ?node-id=62-3

打开该图层的代码预览/播放功能。源文件、字号、断点、搜索、图谱拖动、缩放、复选框状态、处理流程均沿用网页代码。将代码层的预览尺寸设为 1363 × 936 可以对应本包设计稿的基准尺寸。不同宽度会依照原网页的响应式规则调整排版。

代码层通过代码编辑内容，不是逐个原生 Text 图层。完整源码另附 web-source 文件夹，和导入 Figma 的代码保持一致。

## 原生可编辑设计稿

1. 保持本包字体安装，Delight 从作者页面获取。
2. 在 Figma 桌面版使用 Plugins → Development → Import plugin from manifest…，重新导入本包 manifest.json 并运行。
3. 生成全套 81 个页面状态后，点击 Figma 右上角 Present / 播放，在原型预览中点击导航与流程按钮。设计画布中单击用于选择图层，不等同于原型预览。

如果 Figma 要求插件 ID：Development → New plugin → With UI，保留 Figma 自动创建的 manifest.json，将本包 code.js 与 ui.html 复制到生成目录并运行。

本次修复：
- 单行标题、字标和标签使用文字宽度自适应，避免被固定宽度挤成多行。
- 多行正文采用所属容器宽度，而不是浏览器文字外接框的窄宽度。
- 为导航、主流程、历史条目、图谱节点增加从网页提取的原型跳转。
- 增加处理中状态的定时跳转与原型起点。
- 点击连线独立放在 Prototype links 图层组中；编辑正文时可暂时隐藏此组。

原生设计稿仅提供页面跳转和定时跳转。搜索输入、任意图谱拖动和连续缩放等完整行为请使用代码图层。两种形式不能混为一谈。

字体：字标 Bodoni Moda，英文 Delight，俄文 Manrope。字体缺失时版式仍可能不同，原生编辑前请在插件界面检查字体状态。

验证：已复测网页主流程并校验原生原型的跳转目标、文字内容与尺寸策略。Figma 接口仍受 Starter 额度限制，浏览环境 WebGL 不可用，因此本次尚未在真实 Figma 画布验证修复后的原生设计稿，也未验证新代码层在 Figma 内的运行显示。
