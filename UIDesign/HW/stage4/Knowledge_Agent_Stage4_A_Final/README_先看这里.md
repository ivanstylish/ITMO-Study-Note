## 在 Figma 中生成（Windows 桌面版）

### 已有可用的本地开发插件

如果你已有此前 Knowledge Agent 的本地开发插件，可以用它的 manifest.json 安装本版，脚本会保留 Figma 分配的真实插件 ID，并备份原文件。

1. 解压整个文件夹。
2. 右键 `install-into-plugin.ps1` → 使用 PowerShell 运行，选择该插件的 manifest.json。
3. 回到 Figma → Plugins → Development，运行更新后的插件，点击「生成完整可编辑交互原型」。
4. 等待显示完成，使用右上角 **Present / 播放** 查看「Главный сценарий」。图层编辑在设计画布中进行。

### 第一次使用开发插件

1. 在 Figma 桌面版打开你的 Design 文件。
2. Plugins → Development → **New Plugin…**，选择 Figma Design 和 **Custom UI**，保存到一个空文件夹。此步骤让 Figma 分配真实插件 ID。
3. 运行本包的 `install-into-plugin.ps1`，选择刚生成的 manifest.json。脚本只更新这个插件目录内的 code.js、ui.html 和 manifest.json，并先备份原文件。
4. 在 Figma → Plugins → Development 运行该插件，点击「生成完整可编辑交互原型」。
5. 完成后使用 Present 播放。会新增 `Knowledge Agent · A Final · Segoe UI` 页面，现有原型页面不删除。

如果不使用安装脚本，可手动把 `code.js` 和 `ui.html` 复制到 Figma 生成的插件目录，并按本包 manifest.json 的 main、ui、api、editorType、documentAccess、networkAccess 配置更新生成的 manifest，**保留 Figma 生成的 id**。本包 manifest.json 是配置模板，未伪造插件 ID。

如果使用命令行安装：

```powershell
.\install-into-plugin.ps1 -TargetManifest 'D:\你的插件目录\manifest.json'
```

## 展示入口

生成后可从三个原型起点播放：

- `Главный сценарий`：导入 → 分析 → 保存计划 → 报告。
- `Граф знаний`：节点选择、关联查看、80% / 100% / 120% 三档缩放。
- `Восстановление версии`：历史版本查看、取消及确认恢复。

左侧导航、文件选择、历史条目、异常返回、保存计划复选框等通过原型连接操作。模型下拉框由四个原生组件变体实现打开、选择和关闭，选中 Claude Sonnet 后再次展开仍显示该选择。长页面使用纵向滚动。

文件选择采用六条示例数据，非真实操作系统文件选择器。模型、数据库与 Obsidian 均为原型数据，不会访问或修改你的真实笔记。

## 本次修正

| 问题 | 本版处理 |
| --- | --- |
| 文件大小表头与数值不在同一列 | 文件名、大小和操作使用统一列；大小右对齐并使用等宽数字 |
| 文件名长度导致数据列漂移 | 固定大小/操作列，名称占剩余宽度 |
| 文件图标紧贴文字 | 使用明确的图标间距 |
| 圆角外露方形边框 | 使用原生描边，去掉四条矩形拼成的装饰边框 |
| 多余透明点击层妨碍编辑 | 点击连接直接绑定到对应的可见按钮、行或复选框，不覆盖整页透明热区 |
| 正文过细、辅助文字偏浅 | 使用本机 Segoe UI，增加字重及对比度 |
| PDF 坐标还原的部分页面发生重叠 | 改为按语义行排版，保留文字与分支内容 |
| 部分计划中的路径与复选框远离 | 调整行内布局，文件路径贴近对应复选框 |
| 导入文件与结果不对应 | 修正六个文件的目标；重复对话与 Attention 更新进入各自分支 |
| 剪贴板导入进入文本粘贴分支 | 改为独立的剪贴板状态链 |
| 冲突页返回错误、空计划可提交 | 修正返回目标，空计划禁用保存操作 |
| 部分处理页面没有结束跳转 | 覆盖 12 条定时完成跳转，包括第 23 屏 |
| 图谱缩放的文本与连线尺寸不一致 | 导出时同步缩放字体、描边、几何与 SVG 坐标系 |
