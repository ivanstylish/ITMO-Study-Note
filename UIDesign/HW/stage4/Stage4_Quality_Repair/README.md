# 第四阶段 · 对齐、边框与个性化比较

这是当前页面的原生图层修复工具。**尚未在你的 Figma 文件中运行。** Figma 连接返回 Starter 调用额度已用尽，本轮不能读取线上最新画布，也不能代为执行修改。

## 使用

1. 解压，打开第四阶段原型所在的 Figma Design 文件及原生设计页面。
2. Plugins → Development → Import plugin from manifest…，选择本目录 manifest.json 后运行。
3. 点击「检查当前页」，再点击「修复列对齐与圆角外框」。修复作用于当前页面，不跨页扫描。
4. 选中要比较的完整画面（顶层 Frame），点击「生成三个可编辑、可切换的配色比较稿」。未选择时，工具查找名称以 `01 ·` 开头的画面。
5. 在新建的比较页点击 Present，使用顶部 A/B/C 切换方案。比较稿中的文字、矢量、容器均沿用原生图层，可继续编辑。

若 Figma 要求插件 ID，请通过 Plugins → Development → New plugin 创建带 UI 的本地插件，保留 Figma 生成的 manifest.json 与 ID，将本包 code.js、ui.html 放入该插件目录。工具无需联网。

## 已确认的问题与处理

| 范围 | 证据 | 修复方式 |
| --- | --- | --- |
| 文件列表表头与数据 | 截图中「Размер」位于最右端，数值却在中间 | 表头和数据使用相同三列；大小固定 80 px 并右对齐，操作列固定 88 px，列间距 24 px |
| 文件大小列左右漂移 | 本地 6 行采用 space-between，尺寸字段 x 坐标随文件名变化 | 改为 Auto Layout，名称占剩余空间 |
| 文件图标与名称 | 本地导入数据中文字 x=19，图标宽度也为 19 | 名称单元格使用水平 Auto Layout 和 10 px 间距 |
| 圆角按钮外露方形边角 | 截图及本地导入器；四条 Rectangle 充当边框 | 符合几何条件的完整四边框改用原生 inside stroke，圆角保持原值 |
| 同类组件潜在外框问题 | 本地 81 状态中 169 个按钮圆角均为 11；导入器对其他容器使用同样绘边方法 | 修复当前页中具有同样结构的容器及主组件；单边分隔线保留 |

不会把透明点击区域当作装饰外框删除。原型依靠它们进行点击导航。工具不改现有跳转、定时反应与文字内容；实例通常继承当前页主组件的边框修复。其他页面或远程库的主组件不在修复范围。

## 个性化方向

| 方案 | 视觉选择 | 更适合 |
| --- | --- | --- |
| A · 花园档案（推荐） | 现有浅白、嫩绿、深绿 | 保持 Knowledge Agent 已有气质，改动最小 |
| B · 纸本研究 | 暖纸白、墨绿、低饱和草绿 | 长文本阅读、笔记与研究感 |
| C · 星图工作台 | 冷白、灰紫、保留绿色焦点 | 知识图谱与关联探索感 |

参考 Sublime 的知识收藏与关联发现方向，以及 Readymag 的编辑式排版探索。这里提供的是三套配色比较稿；没有将原型整体重排，也没有声称实现完整主题系统。原稿不变，比较稿位于新页。比较稿保留源画面的原有流程跳转，因此进入后续画面会回到原稿配色；A/B/C 标签在三张比较稿之间切换。

## 验证范围

已通过 JavaScript 语法检查及基于本地 scenes.json 的 API 模拟测试：81 个原画面、3171 个文本节点保留，483 个符合条件的四边框可转换，6 行文件列可对齐；重复运行不重复转换描边或添加占位列。三套比较画面及 9 条 A/B/C 导航连接经过结构检查。

测试覆盖了圆角保持、已有反应保留、单边分隔线保留、几何不一致时跳过、带交互的边框不删除，以及再次运行的结果。

**尚未验证：线上最新文件是否与本地版本相同、真实 Figma API 执行、字体可用性、画布渲染、Present 点击播放、响应式文本变化。** 当前工具不进入 Code Layer 内部修改 HTML/CSS，也不把 Code Layer 转为原生图层。保留原型已有的能力，不会自动新增任意文字输入、连续缩放等交互。

若检查显示 0 个可修复对象，可能当前页是 Code Layer、静态图像，或图层结构与本地导入版不同；应停止应用此修复，不能据此认定设计没有问题。

verify.cjs 是本地验证脚本，不需要导入 Figma。
